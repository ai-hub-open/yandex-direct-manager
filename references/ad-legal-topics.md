# Лицензируемые и запрещённые тематики рекламы (РФ)

Вход для **Шага 0** (поле брифа «лицензируемая/запрещённая тематика + документы» и стоп-гейт) и **Шага 8** (проверка объявлений перед сдачей). Источник — справка Директа, разделы №336–418, сводка №419. Даты/номера сверены 2026-07-15 по `direct_skill_gap_report.md` (Приложение А).

## Стоп-гейт: полностью запрещены в РФ (№419)

Если тематика продукта из этого списка — **пайплайн останавливается**, кампанию в Директе не запустить:

- Азартные игры, казино, ставки вне легальных букмекеров.
- Оружие любых видов и военная продукция.
- Табак, курительные принадлежности, вейпы.
- Наркотики, прекурсоры, **рецептурные лекарства**.
- Аборты, онлайн-диагноз.
- Копии/реплики брендов.
- Финансовые пирамиды, «заработок с гарантией».
- Политическая реклама.
- Криптовалюта.
- VPN и обход блокировок.
- Скрутка пробега/счётчиков.
- Дипломы/диссертации на заказ.

На такой тематике скилл прямо сообщает маркетологу, что запуск невозможен, и не тратит шаги на семантику/объявления.

## Ограничены — нужны документы

Тематика допускается, но требует документов и спец-разметки. В брифе (Шаг 0) фиксируем, **есть ли документы**; без них — предупреждение и блок до предоставления:

| Тематика | Что нужно |
|---|---|
| Медуслуги | Медицинская лицензия |
| Медизделия | Регистрационное удостоверение |
| Аптеки/лекарства | Фарм. лицензия (+ Росздравнадзор для доставки) |
| БАД | Свидетельство о госрегистрации |
| Финансы/банки/МФО/ломбарды/страхование/форекс/инвестиции | Профильные лицензии/реестры |
| Алкоголь | Лицензия/сертификат; без дистанционной продажи |
| Букмекеры | Лицензия; размещение **только в РСЯ** |
| Лотереи | Решение Правительства РФ |
| Новостройки/застройщики | Данные застройщика + наш.дом.рф |
| Сертификация | Аттестат аккредитации |
| Дистанционная торговля | Реквизиты продавца |

Полный перечень с номерами статей — №336–418.

## Автопредупреждения Директа (№334)

Для ряда тематик (финансы, медицина, БАД и др.) Директ **сам вставляет предупреждающий текст** в объявление («Есть противопоказания…», «...не является публичной офертой» и т.п.). Это **съедает символы** и меняет вид объявления — учитывать при копирайтинге на Шаге 8 (не рассчитывать на полный лимит заголовка/текста в таких нишах).

## Закон о рекламе (общее, для всех ниш)

- **Маркировка ОРД** — обязательна для всей платной рекламы (включить автомаркировку в кабинете).
- **Реквизиты рекламодателя** — ИНН/ОГРН (для ИП — ОГРНИП).
- **Возрастная маркировка** 18+ где применимо.
- **Условия акций** — при «скидка N%» указать условия и срок.
