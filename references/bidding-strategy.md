# Bidding Strategy — стратегия торгов и эволюция автостратегий

Используется на Шаге 9 пайплайна (после Метрики, перед заливкой через MCP). Задача — **подобрать правильную стратегию торгов для каждой кампании с учётом её этапа жизни**.

Самая частая ошибка маркетологов — сразу ставить «Оптимизацию конверсий» при запуске. Алгоритм Яндекса требует **от 10 конверсий в неделю** для обучения; без этого он либо переплачивает за случайные клики, либо вообще не показывает рекламу.

## Главный принцип — эволюция через три фазы

Стратегия торгов — это **не одна настройка**, а **эволюция через три фазы**:

| Фаза | Когда | Цель | Стратегия |
|------|-------|------|-----------|
| **1. Старт (обучение)** | 0-2 недели | Накопить статистику, понять кликабельность | «Максимум кликов с недельным бюджетом» с лимитом CPC, ИЛИ ручные ставки |
| **2. Промежуточная** | 2-4 недели | Подтвердить конверсию ≥10/нед | Та же стратегия + «Целевая стоимость клика» |
| **3. Масштаб (конверсии)** | 4+ недели, ≥10 конв/нед | Оптимизировать CPL | «Оптимизация конверсий» или «Оплата за конверсию» |

Без Фазы 1 алгоритм идёт «на удачу». Без Фазы 3 мы не используем главное преимущество Директа (машинное обучение).

## Что НЕ делаем

- Не настраиваем минусы, корректировки, гео — это другие шаги.
- Не пишем тексты объявлений.
- Не считаем общий бюджет — это стратегический слой / `frequency-calculator`.
- Не выбираем тип кампании (Поиск vs РСЯ vs МК) — это `wordstat-filter` и структура.

## Вход

1. **Список кампаний** с типами (Поиск / РСЯ / Ретаргет) — из `05_campaign_structure.json`.
2. **Бюджеты по кампаниям** — из `05_campaign_structure.json` (берётся из брифа поле 4 + распределения поле 5).
3. **Целевой CPC** для каждой кампании — из `02_frequency.json`.
4. **Целевой CPA / CPL** (если известен) — из `00_brief.md` (поле 9).
5. **`07_metrika_goals.json` из Шага 7** — критичный вход. Оттуда `counter_id` для привязки и `goal_id` для каждой кампании (макро для оптимизации в Фазе 3, микро — для отчётов). Без `07_metrika_goals.json` **Фаза 3 невозможна** — алгоритму не на что оптимизироваться.
6. **Состояние коллтрекинга** — критично для срочного спроса. Из `00_brief.md` (поле 9). Без коллтрекинга оптимизация по конверсиям невозможна.
7. **Тип ниши** — определит «когда и как переключать».

Если входа не хватает:
```
Чтобы выбрать стратегию торгов:
1. Сколько кампаний и каких (имена + Поиск/РСЯ/Ретаргет)?
2. Бюджет по каждой?
3. Целевой CPC и CPA (если знаешь)?
4. Коллтрекинг настроен? (Calltouch, Callibri, Roistat — что именно?)
5. Это первая кампания или у клиента уже накоплены данные в Метрике?
```

## Фаза 1. Стартовая стратегия по типу кампании

| Тип кампании | Стартовая стратегия | Почему |
|---------------|---------------------|--------|
| **Поиск (горячие транзакционные)** | Максимум кликов + лимит CPC | Чёткий спрос, нужна статистика, конкуренция управляема |
| **Поиск (категорийные ВЧ)** | Ручные ставки | Дорогие клики, нельзя пускать алгоритм без контроля |
| **Поиск (НЧ-сегментные)** | Максимум кликов + лимит CPC | Дешёвые клики, объём небольшой, нужно набрать |
| **РСЯ (категорийные)** | Оплата за конверсии с CPA-лимитом | Защита от слива на ботов. Никаких ручных или Max Clicks в РСЯ. |
| **РСЯ (look-alike)** | Оплата за конверсии с CPA-лимитом | То же |
| **Ретаргетинг** | Максимум кликов + лимит CPC | Аудитория тёплая, ROI сразу понятен |

**Никогда на старте:**
- ❌ «Оптимизация конверсий» без накопленных данных
- ❌ «Оптимизация рентабельности (ROI)» — требует ещё больше данных
- ❌ Только Мастер кампаний — это backup, не основа

## Фаза 2. Триггеры переключения

Каждая кампания получает условия перехода:

```
Кампания: К1 «Премиум-оригинал» (Поиск)
Стартовая стратегия: Максимум кликов + лимит CPC 250₽
Бюджет: 20 000 ₽/мес

Триггеры перехода на Фазу 2 (Промежуточная):
- ✅ Прошло 2 недели OR накоплено 300+ кликов
- ✅ CTR ≥ 4% (целевой для премиум-сегмента)
- ✅ CPL ≤ 2 500 ₽ или есть 5+ конверсий
- Действие: добавить «Целевая стоимость клика» 200₽, держать ту же стратегию

Триггеры перехода на Фазу 3 (Масштаб):
- ✅ 10+ конверсий в неделю стабильно (две недели подряд)
- ✅ Коллтрекинг настроен и подтверждает конверсии
- ✅ CTR ≥ 5%, CR ≥ 2%
- Действие: переключить на «Оптимизация конверсий» с CPA-лимитом 2 200₽

Триггеры остановки или корректировки:
- ⚠️ CTR < 2% после первой недели → пересмотреть объявления (не стратегию)
- ⚠️ CPL > 4 000 ₽ после 2 недель → отключить ВЧ-маски или сузить ЦА
- ⚠️ 0 конверсий за 2 недели → проверять сайт/коллтрекинг, не Директ
```

## Фаза 3. Адаптация под нишу

См. «Фазы стратегий по нишам» ниже.

- **Срочный спрос:** фаза обучения 1-2 недели, переход на конверсии только при коллтрекинге. Часто оптимизация по «звонок» а не «форма».
- **B2B SaaS:** длинный цикл (триал через 3 недели). Составная цель «демо-заявка + start_trial». Фаза обучения 4-6 недель.
- **Премиум:** маленький объём конверсий — часто остаёмся на «Оптимизация кликов» навсегда + «Целевая стоимость клика». Фаза 3 не для всех.
- **Ручная работа / на заказ:** аналогично премиуму — длинный цикл + малый объём → Фаза 3 только при бюджете 80к+/мес.
- **Массовые услуги:** быстрая Фаза 1 (2 недели), быстрый переход. CR обычно высокий.

## Фазы стратегий по нишам

### Срочный спрос (active demand)

**Признаки:** эвакуатор, такси, аварийный сантехник, заклинило замок, ветеринар скорая.

**Тайминги:**
- Фаза 1: 7-14 дней (трафик быстрый — статистика за неделю в крупном городе)
- Фаза 2: 7 дней
- Фаза 3: через 14-21 день при наличии коллтрекинга

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Максимум кликов + лимит CPC | CPC из `02_frequency.json` (базовый) |
| 2 | + Целевая стоимость клика | tCPC = базовый × 0.9 |
| 3 | Оптимизация конверсий с CPA-лимитом | CPA по «звонок» (НЕ форма!) |

**Критическое: коллтрекинг обязателен.** 90%+ конверсий — звонки. Без коллтрекинга (Calltouch, Callibri, UIS, MANGO) переход в Фазу 3 невозможен.

**НЕ делать:**
- ❌ Сразу «Оптимизация конверсий» (без 10 звонков/нед алгоритм не учится)
- ❌ Оптимизация по форме (форму в срочном спросе почти не заполняют)
- ❌ Низкий CPC-лимит (упустим горячий трафик во время аварии)

### B2B SaaS

**Признаки:** CRM, ERP, бухучёт, специализированный софт.

**Тайминги:**
- Фаза 1: 14-21 день (цикл длинный, статистика накапливается медленно)
- Фаза 2: 14-21 день
- Фаза 3: 4-6 недель от старта при 10+ конверсий/нед

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Ручные ставки или Max clicks + лимит CPC | CPC ≤ 300 ₽ на старте |
| 2 | + Целевая стоимость клика | tCPC = базовый × 0.85 |
| 3 | Оптимизация конверсий по составной цели | CPA по составной: «демо-заявка + триал» |

**Особенности:**
- **Составная цель** в Метрике обязательна (не одна «отправил форму», а связка «отправил → активировал триал → не отменил через 7 дней»). Без этого алгоритм оптимизируется на не-целевых лидов.
- **Длинный цикл сделки:** триал 14 дней, оплата через 7 — итого от клика до конверсии 3 недели. Данные о Фазе 3 видны не раньше чем через месяц.
- **Look-alike по существующим клиентам** — обязательно подключить.

**НЕ делать:**
- ❌ Оптимизация по простой «заявке» — алгоритм притащит холодных
- ❌ Спешка с Фазой 3 (раньше 4 недель — алгоритм не понял воронку)
- ❌ Слишком жёсткий CPA-лимит — для B2B SaaS CPA 8-15к ₽ это норма

### Премиум-сегмент

**Признаки:** авторская живопись, элитная недвижимость, luxury-часы, дизайнерская одежда.

**Тайминги:**
- Фаза 1: 14-21 день
- Фаза 2: 14-21 день
- Фаза 3: часто **не наступает** из-за малого объёма

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Ручные ставки | CPC высокий: 300-1500 ₽ в зависимости от ниши |
| 2 | Целевая стоимость клика | tCPC на уровне Фазы 1 |
| 3 (опц.) | Только при бюджете 200к+/мес и 10+ конв/нед | Оптимизация конверсий + ретаргет |

**Особенности:**
- В премиуме часто **остаёмся на Фазе 2 навсегда**. Не «провал», специфика ниши.
- Большая часть бюджета — на **РСЯ + ретаргет**, не Поиск. На РСЯ — оплата за конверсии с высоким CPA-лимитом.
- **Длинный цикл сделки** (1-3 месяца). Конверсия маленькая, чек огромный — экономика на чеке.

**НЕ делать:**
- ❌ Стремиться к 10 конв/нед — для премиума нереалистично
- ❌ Низкий CPC-лимит — отсекаем целевую ЦА (премиум-клиент гуглит дороже)
- ❌ Массовый CPA — он будет в 5-10 раз выше, чем в массмаркете

### Ручная работа / на заказ

**Признаки:** картины ручной работы, мебель на заказ, торты, авторская керамика.

**Тайминги:**
- Фаза 1: 10-14 дней
- Фаза 2: 14 дней
- Фаза 3: через 4-6 недель только при бюджете 80к+/мес

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Максимум кликов + лимит CPC | CPC 150-300 ₽ |
| 2 | + Целевая стоимость клика | tCPC = базовый × 0.9 |
| 3 (опц.) | Оптимизация конверсий | CPA 1500-3000 ₽ |

**Особенности:**
- Похоже на премиум, но менее экстремально. Конверсия реалистичная (10/нед на бюджет 80к — возможно для подарочного).
- **Подарочные сегменты** имеют сезонные пики — стратегию переключаем чаще (14.02, 8.03, май, декабрь).
- **B2B-сегменты** (для дизайнеров) часто требуют отдельной стратегии — Фаза 3 не наступает из-за маленького объёма.

### Массовые услуги

**Признаки:** доставка пиццы, ремонт телефонов, клининг, химчистка.

**Тайминги:**
- Фаза 1: 7 дней
- Фаза 2: 7 дней
- Фаза 3: через 14 дней

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Максимум кликов + лимит CPC | CPC 50-200 ₽ |
| 2 | + Целевая стоимость клика | tCPC = базовый × 0.85 |
| 3 | Оптимизация конверсий | CPA из брифа (обычно 200-800 ₽) |

**Особенности:**
- Самый быстрый цикл обучения — статистика набирается быстро, конверсия высокая.
- Конкуренция с маркетплейсами — главный риск. Если CPC растёт неуправляемо, сужаем гипотезы.
- **Сезонность** влияет (доставка пиццы пятничным вечером — пик; ремонт телефонов после школы — пик).

## Лестница сложности (порядок переключения)

```
Ручные ставки
    ↓ (после 1 нед данных)
Максимум кликов + лимит CPC
    ↓ (после 2 нед)
+ Целевая стоимость клика
    ↓ (после 10 конв/нед, 2 нед подряд)
Оптимизация конверсий с CPA-лимитом
    ↓ (после 30 конв/нед, стабильно)
Оптимизация рентабельности (ROI)
```

**Нельзя «перепрыгнуть» через ступеньку.** Каждая даёт алгоритму данные для следующей.

## Универсальные анти-паттерны

- **Не переключать стратегию каждую неделю.** Дай 2-3 недели на обучение. Преждевременное переключение сбрасывает.
- **Не запускать «Оптимизация рентабельности» (ROAS).** Самая сложная стратегия, нужны точные данные о выручке по каждой конверсии. Большинство бизнесов до этого не дорастают.
- **Не использовать «Целевая доля рекламных расходов»** на старте — она для зрелых кампаний с большим оборотом.
- **Не верить «Мастер кампаний» как единственному решению.** Хорош только при больших данных или для быстрого старта.

## Если ниша не из списка

Универсальная последовательность: Max clicks → +tCPC → Conv Opt. Тайминги 14/14/21 день, конверсии 10/нед как минимум. Помечай: `niche_template: default`.

## Особые случаи

### ЕПК (`ad_model = epk_combined`)

В ЕПК Поиск и РСЯ живут в **одной** кампании, поэтому раздельных Поиск/РСЯ-стратегий нет — **одна стратегия на РК**. Стартовая логика та же по духу: не начинать с «Оптимизации конверсий». Практика для ЕПК:

- **Старт:** «Максимум кликов» с недельным бюджетом и лимитом CPC (или пакетная стратегия аккаунта, если ведёте несколько ЕПК).
- **После накопления 10+ конверсий/нед стабильно** — «Оплата за конверсию» / «Максимум конверсий» с CPA-лимитом по цели из `07_metrika_goals.json`.
- Отдельной «РСЯ нельзя на ручных» оговорки не требуется — сеть внутри той же кампании ведёт автостратегия.
- В `09_bidding_strategy.json` для ЕПК-кампаний поле `"channel": "epk"`.

Всё остальное (триггеры фаз, коллтрекинг как gate для Фазы 3, ниши) применяется как для Поиска.

### Один кампания всего
Делаем стратегию для неё одной, без сравнений. Гейт короткий.

### Без коллтрекинга совсем
Фаза 3 (Оптимизация конверсий) **невозможна**. Останавливаемся на Фазе 2 (CPC-оптимизация). Прямо: «без коллтрекинга кампания не пойдёт дальше оптимизации кликов. Если в нише важны звонки (срочный спрос, B2B) — поставь коллтрекинг до запуска, иначе теряем 30-50% эффективности».

### Только РСЯ (формирование спроса)
На РСЯ практически **никогда не используем ручные ставки и Max Clicks** — нужно «Оплата за конверсии с CPA-лимитом», иначе бюджет уйдёт на бот-площадки.

### Только МК (Мастер кампаний)
Предупреди: «МК — это backup-вариант, а не основной. Для бюджета >50к/мес рекомендую делать поисковые ручные + РСЯ с конверсиями».

### Накопленные данные есть с прошлой кампании
Если у клиента уже >200 конверсий за 6 мес — можно **пропустить Фазу 1**: на старте сразу «Оптимизация конверсий» с CPA-лимитом по историческим. Редкий случай.

## Стиль работы

- **Не «правильная стратегия одна на всех».** Для каждой кампании своя.
- **Триггеры цифрами, не интуицией.** «Когда будет лучше» — не план. «10 конв/нед + CTR ≥4% две недели подряд» — план.
- **Коллтрекинг — gate-критерий.** Не идём в Фазу 3 без него.
- **Стартовая стратегия проста.** Чем больше параметров на старте — тем больше шансов, что один из них ошибочный.

## Связи в пайплайне

- **Вход:**
  - Кампании из `05_campaign_structure.json` + бюджеты из `00_brief.md` (поле 4-5)
  - CPC из `02_frequency.json`, CPL/CPA из `00_brief.md` (поле 9)
  - **`07_metrika_goals.json` от `metrika-goals-setup`** — критичный. counter_id для привязки + goal_id для каждой кампании.
  - Для B2B SaaS — обязательно `goal_id` составной цели (тип `step`), не простой.
- **Выход:** `09_bidding_strategy.json` → используется при заливке через MCP (Шаг 10). В JSON для каждой кампании поле `optimization_goal_id` и `additional_goal_ids` — это `goal_id` из `07_metrika_goals.json`.
