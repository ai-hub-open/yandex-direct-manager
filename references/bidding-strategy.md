# Bidding Strategy — стратегия торгов и эволюция автостратегий

Используется на Шаге 9 пайплайна (после Метрики, перед заливкой через MCP). Задача — **подобрать правильную стратегию торгов для каждой кампании с учётом её этапа жизни**.

Самая частая ошибка маркетологов — сразу ставить «Максимум конверсий» при запуске. Алгоритм Яндекса требует **от 10 конверсий в неделю** для обучения (порог подтверждён справкой Директа, №247; **для приложений — 70 конверсий/нед**); без этого он либо переплачивает за случайные клики, либо вообще не показывает рекламу.

## Главный принцип — эволюция через три фазы

Стратегия торгов — это **не одна настройка**, а **эволюция через три фазы**:

| Фаза | Когда | Цель | Стратегия |
|------|-------|------|-----------|
| **1. Старт (обучение)** | 0-2 недели | Накопить статистику, понять кликабельность | «Максимум кликов» с ограничением «средняя цена клика», ИЛИ ручные ставки |
| **2. Промежуточная** | 2-4 недели | Подтвердить конверсию ≥10/нед | Та же стратегия + ужесточить ограничение средней цены клика |
| **3. Масштаб (конверсии)** | 4+ недели, ≥10 конв/нед | Оптимизировать CPL | «Максимум конверсий» (за клики / за конверсии) |

Без Фазы 1 алгоритм идёт «на удачу». Без Фазы 3 мы не используем главное преимущество Директа (машинное обучение).

## Что НЕ делаем

- Не настраиваем минусы, корректировки, гео — это другие шаги.
- Не пишем тексты объявлений.
- Не считаем общий бюджет — это стратегический слой / `frequency-calculator`.
- Не выбираем тип кампании (Поиск vs РСЯ vs МК) — это `wordstat-filter` и структура.

## Вход

1. **Список кампаний** с типами (Поиск / РСЯ / Ретаргет) — из `05_campaign_structure.json`.
2. **Бюджеты по кампаниям** — из `05_campaign_structure.json` (берётся из брифа поле 4 + распределения поле 5).
3. **Целевой CPC** для каждой кампании — из `02_frequency.json`.
4. **Целевой CPA / CPL** (если известен) — из `00_brief.md` (поле 9).
5. **`07_metrika_goals.json` из Шага 7** — критичный вход. Оттуда `counter_id` для привязки и `goal_id` для каждой кампании (макро для оптимизации в Фазе 3, микро — для отчётов). Без `07_metrika_goals.json` **Фаза 3 невозможна** — алгоритму не на что оптимизироваться.
6. **Состояние коллтрекинга** — критично для срочного спроса. Из `00_brief.md` (поле 9). Без коллтрекинга оптимизация по конверсиям невозможна.
7. **Тип ниши** — определит «когда и как переключать».

Если входа не хватает:
```
Чтобы выбрать стратегию торгов:
1. Сколько кампаний и каких (имена + Поиск/РСЯ/Ретаргет)?
2. Бюджет по каждой?
3. Целевой CPC и CPA (если знаешь)?
4. Коллтрекинг настроен? (Calltouch, Callibri, Roistat — что именно?)
5. Это первая кампания или у клиента уже накоплены данные в Метрике?
```

## Фаза 1. Стартовая стратегия по типу кампании

| Тип кампании | Стартовая стратегия | Почему |
|---------------|---------------------|--------|
| **Поиск (горячие транзакционные)** | «Максимум кликов» с ограничением средней цены клика | Чёткий спрос, нужна статистика, конкуренция управляема |
| **Поиск (категорийные ВЧ)** | Ручные ставки | Дорогие клики, нельзя пускать алгоритм без контроля |
| **Поиск (НЧ-сегментные)** | «Максимум кликов» с ограничением средней цены клика | Дешёвые клики, объём небольшой, нужно набрать |
| **Поведение сети (РСЯ) внутри комбинаторной РК** | «Максимум конверсий» с оплатой за конверсии и CPA-лимитом | Защита от слива на ботов: сеть отдаём автостратегии, не ручным |
| **Look-alike (сеть)** | «Максимум конверсий» с оплатой за конверсии и CPA-лимитом | То же |
| **Ретаргетинг** | «Максимум кликов» с ограничением средней цены клика | Аудитория тёплая, ROI сразу понятен |

**Никогда на старте:**
- ❌ «Максимум конверсий» без накопленных данных
- ❌ Ограничение по ДРР внутри «Максимум конверсий» (или β-стратегия «Максимум прибыли») — требует ещё больше данных
- ❌ Только Мастер кампаний — это backup, не основа

## Фаза 2. Триггеры переключения

Каждая кампания получает условия перехода:

```
Кампания: К1 «Премиум-оригинал» (Поиск)
Стартовая стратегия: «Максимум кликов» с ограничением средней цены клика 250₽
Бюджет: 20 000 ₽/мес

Триггеры перехода на Фазу 2 (Промежуточная):
- ✅ Прошло 2 недели OR накоплено 300+ кликов
- ✅ CTR ≥ 4% (целевой для премиум-сегмента)
- ✅ CPL ≤ 2 500 ₽ или есть 5+ конверсий
- Действие: ужесточить ограничение средней цены клика до 200₽, держать ту же стратегию

Триггеры перехода на Фазу 3 (Масштаб):
- ✅ 10+ конверсий в неделю стабильно (две недели подряд; порог подтверждён справкой, №247)
- ✅ Коллтрекинг настроен и подтверждает конверсии
- ✅ CTR ≥ 5%, CR ≥ 2%
- Действие: переключить на «Максимум конверсий» с CPA-лимитом 2 200₽

Триггеры остановки или корректировки:
- ⚠️ CTR < 2% после первой недели → пересмотреть объявления (не стратегию)
- ⚠️ CPL > 4 000 ₽ после 2 недель → отключить ВЧ-маски или сузить ЦА
- ⚠️ 0 конверсий за 2 недели → проверять сайт/коллтрекинг, не Директ
```

## Фаза 3. Адаптация под нишу

См. «Фазы стратегий по нишам» ниже.

- **Срочный спрос:** фаза обучения 1-2 недели, переход на конверсии только при коллтрекинге. Часто оптимизация по «звонок» а не «форма».
- **B2B SaaS:** длинный цикл (триал через 3 недели). Составная цель «демо-заявка + start_trial». Фаза обучения 4-6 недель.
- **Премиум:** маленький объём конверсий — часто остаёмся на «Максимум кликов» с ограничением средней цены клика навсегда. Фаза 3 не для всех.
- **Ручная работа / на заказ:** аналогично премиуму — длинный цикл + малый объём → Фаза 3 только при бюджете 80к+/мес.
- **Массовые услуги:** быстрая Фаза 1 (2 недели), быстрый переход. CR обычно высокий.

## Маппинг в API

Человеческие названия стратегий Директа не совпадают с типами в API. Таблица — контракт между этим шагом и заливкой; полный список типов и их обязательных параметров — в `yandex-direct-mcp.md`.

| Фаза и название в интерфейсе | `type` | Обязательные параметры | Опциональные |
|---|---|---|---|
| Ф1 «Максимум кликов» с недельным бюджетом | `WB_MAXIMUM_CLICKS` | `weekly_spend_limit` | `bid_ceiling` — потолок цены клика |
| Ф2 то же с ограничением средней цены клика | `AVERAGE_CPC` | `average_cpc` | `weekly_spend_limit` |
| Ф3 «Максимум конверсий» с оплатой за конверсии | `PAY_FOR_CONVERSION` | `cpa`, `goal_id` | `weekly_spend_limit` |
| Ф3 «Максимум конверсий» без оплаты за конверсии | `AVERAGE_CPA` | `average_cpa`, `goal_id` | `weekly_spend_limit`, `bid_ceiling` |
| «Максимум конверсий» с ограничением по ДРР | `AVERAGE_CRR` | `crr` (%), `goal_id` | `weekly_spend_limit` |
| Ручные ставки на Поиске | `HIGHEST_POSITION` | — | `daily_budget` на кампании + ставки через `keywordbids_set` |
| Сторона выключена | `SERVING_OFF` | — | — |

**Три правила, которые ломают заливку, если их нарушить:**

1. **Недельный бюджет — это `weekly_spend_limit` внутри стратегии, а не `daily_budget` кампании.** `daily_budget` применим только к ручным ставкам. Передать недельный бюджет как дневной — значит выставить расход в семь раз выше задуманного.
2. **Деньги передаются в валюте аккаунта** (рубли), конвертация в микроединицы происходит внутри моста. Не умножай на 1 000 000 сам.
3. **Конверсионные стратегии требуют `goal_id`** — он берётся из `07_metrika_goals.json` (`campaigns_binding[].macro_goal_id`). Нет целей — Фаза 3 недоступна технически, а не только методологически.

### Ставки при разных стратегиях

- **Автостратегия** — ставок нет, есть приоритет фразы: `keywordbids_set({bids: [{ad_group_id, strategy_priority: "NORMAL"}]})`.
- **Ручная** — целевая ставка из `02_frequency.json`: `keywordbids_set({bids: [{ad_group_id, search_bid: 25}]})`. Уровень группы закрывает все её фразы одним элементом.

Триггеры мониторинга: CTR/CPL/CR ежедневно первые 2 недели, потом еженедельно.

Прямой вопрос: «Подходит план? Коллтрекинг настроен? Запускаем?»

Если коллтрекинг не настроен — **критично**: предупреди, что без него Фаза 3 невозможна, и кампания «застрянет» на «Максимуме кликов» навсегда.

## Фазы стратегий по нишам

### Срочный спрос (active demand)

**Признаки:** эвакуатор, такси, аварийный сантехник, заклинило замок, ветеринар скорая.

**Тайминги:**
- Фаза 1: 7-14 дней (трафик быстрый — статистика за неделю в крупном городе)
- Фаза 2: 7 дней
- Фаза 3: через 14-21 день при наличии коллтрекинга

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | «Максимум кликов» с ограничением средней цены клика | ср. цена клика из `02_frequency.json` (базовый) |
| 2 | Ужесточить ограничение средней цены клика | ср. цена клика = базовый × 0.9 |
| 3 | «Максимум конверсий» с CPA-лимитом | CPA по «звонок» (НЕ форма!) |

**Критическое: коллтрекинг обязателен.** 90%+ конверсий — звонки. Без коллтрекинга (Calltouch, Callibri, UIS, MANGO) переход в Фазу 3 невозможен.

**НЕ делать:**
- ❌ Сразу «Максимум конверсий» (без 10 звонков/нед алгоритм не учится)
- ❌ Оптимизация по форме (форму в срочном спросе почти не заполняют)
- ❌ Низкое ограничение средней цены клика (упустим горячий трафик во время аварии)

### B2B SaaS

**Признаки:** CRM, ERP, бухучёт, специализированный софт.

**Тайминги:**
- Фаза 1: 14-21 день (цикл длинный, статистика накапливается медленно)
- Фаза 2: 14-21 день
- Фаза 3: 4-6 недель от старта при 10+ конверсий/нед

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Ручные ставки или «Максимум кликов» с ограничением средней цены клика | ср. цена клика ≤ 300 ₽ на старте |
| 2 | Ужесточить ограничение средней цены клика | ср. цена клика = базовый × 0.85 |
| 3 | «Максимум конверсий» по составной цели | CPA по составной: «демо-заявка + триал» |

**Особенности:**
- **Составная цель** в Метрике обязательна (не одна «отправил форму», а связка «отправил → активировал триал → не отменил через 7 дней»). Без этого алгоритм оптимизируется на не-целевых лидов.
- **Длинный цикл сделки:** триал 14 дней, оплата через 7 — итого от клика до конверсии 3 недели. Данные о Фазе 3 видны не раньше чем через месяц.
- **Look-alike по существующим клиентам** — обязательно подключить.

**НЕ делать:**
- ❌ Оптимизация по простой «заявке» — алгоритм притащит холодных
- ❌ Спешка с Фазой 3 (раньше 4 недель — алгоритм не понял воронку)
- ❌ Слишком жёсткий CPA-лимит — для B2B SaaS CPA 8-15к ₽ это норма

### Премиум-сегмент

**Признаки:** авторская живопись, элитная недвижимость, luxury-часы, дизайнерская одежда.

**Тайминги:**
- Фаза 1: 14-21 день
- Фаза 2: 14-21 день
- Фаза 3: часто **не наступает** из-за малого объёма

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | Ручные ставки | ср. цена клика высокая: 300-1500 ₽ в зависимости от ниши |
| 2 | «Максимум кликов» с ограничением средней цены клика | ограничение на уровне Фазы 1 |
| 3 (опц.) | Только при бюджете 200к+/мес и 10+ конв/нед | «Максимум конверсий» + ретаргет |

**Особенности:**
- В премиуме часто **остаёмся на Фазе 2 навсегда**. Не «провал», специфика ниши.
- Большая часть бюджета — на **сеть (РСЯ) + ретаргет**, не Поиск. Сеть внутри комбинаторной ЕПК (или экспертный вариант «только РСЯ») ведёт «Максимум конверсий» с оплатой за конверсии и высоким CPA-лимитом.
- **Длинный цикл сделки** (1-3 месяца). Конверсия маленькая, чек огромный — экономика на чеке.

**НЕ делать:**
- ❌ Стремиться к 10 конв/нед — для премиума нереалистично
- ❌ Низкое ограничение средней цены клика — отсекаем целевую ЦА (премиум-клиент гуглит дороже)
- ❌ Массовый CPA — он будет в 5-10 раз выше, чем в массмаркете

### Ручная работа / на заказ

**Признаки:** картины ручной работы, мебель на заказ, торты, авторская керамика.

**Тайминги:**
- Фаза 1: 10-14 дней
- Фаза 2: 14 дней
- Фаза 3: через 4-6 недель только при бюджете 80к+/мес

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | «Максимум кликов» с ограничением средней цены клика | ср. цена клика 150-300 ₽ |
| 2 | Ужесточить ограничение средней цены клика | ср. цена клика = базовый × 0.9 |
| 3 (опц.) | «Максимум конверсий» | CPA 1500-3000 ₽ |

**Особенности:**
- Похоже на премиум, но менее экстремально. Конверсия реалистичная (10/нед на бюджет 80к — возможно для подарочного).
- **Подарочные сегменты** имеют сезонные пики — стратегию переключаем чаще (14.02, 8.03, май, декабрь).
- **B2B-сегменты** (для дизайнеров) часто требуют отдельной стратегии — Фаза 3 не наступает из-за маленького объёма.

### Массовые услуги

**Признаки:** доставка пиццы, ремонт телефонов, клининг, химчистка.

**Тайминги:**
- Фаза 1: 7 дней
- Фаза 2: 7 дней
- Фаза 3: через 14 дней

**Стратегии:**

| Фаза | Стратегия | Параметры |
|------|-----------|-----------|
| 1 | «Максимум кликов» с ограничением средней цены клика | ср. цена клика 50-200 ₽ |
| 2 | Ужесточить ограничение средней цены клика | ср. цена клика = базовый × 0.85 |
| 3 | «Максимум конверсий» | CPA из брифа (обычно 200-800 ₽) |

**Особенности:**
- Самый быстрый цикл обучения — статистика набирается быстро, конверсия высокая.
- Конкуренция с маркетплейсами — главный риск. Если CPC растёт неуправляемо, сужаем гипотезы.
- **Сезонность** влияет (доставка пиццы пятничным вечером — пик; ремонт телефонов после школы — пик).

## Лестница сложности (порядок переключения)

```
Ручные ставки
    ↓ (после 1 нед данных)
«Максимум кликов» с ограничением средней цены клика
    ↓ (после 2 нед)
Ужесточить ограничение средней цены клика
    ↓ (после 10 конв/нед, 2 нед подряд)
«Максимум конверсий» с CPA-лимитом
    ↓ (после 30 конв/нед, стабильно)
Ограничение по ДРР внутри «Максимум конверсий» (или β-стратегия «Максимум прибыли»)
```

**Нельзя «перепрыгнуть» через ступеньку.** Каждая даёт алгоритму данные для следующей.

## Универсальные анти-паттерны

- **Не переключать стратегию каждую неделю.** Дай 2-3 недели на обучение. Преждевременное переключение сбрасывает.
- **Не запускать оптимизацию по ДРР / β-стратегию «Максимум прибыли» на старте.** Самый сложный режим, нужны точные данные о выручке по каждой конверсии. Большинство бизнесов до этого не дорастают.
- **Не включать ограничение по ДРР** на старте — оно для зрелых кампаний с большим оборотом.
- **Не верить «Мастер кампаний» как единственному решению.** Хорош только при больших данных или для быстрого старта.

## Если ниша не из списка

Универсальная последовательность: «Максимум кликов» с ограничением средней цены клика → ужесточение этого ограничения → «Максимум конверсий». Тайминги 14/14/21 день, конверсии 10/нед как минимум. Помечай: `niche_template: default`.

## Комбинаторная ЕПК — одна стратегия на РК

В комбинаторной ЕПК Поиск и РСЯ живут в **одной** кампании → **одна стратегия на РК**. Раздельных Поиск/РСЯ-стратегий нет. Стартовая логика та же по духу: не начинать с «Максимум конверсий». Практика:

- **Старт:** «Максимум кликов» с недельным бюджетом и ограничением средней цены клика (или пакетная стратегия аккаунта, если ведёте несколько РК).
- **После накопления 10+ конверсий/нед стабильно** — «Максимум конверсий» с оплатой за конверсии и CPA-лимитом по цели из `07_metrika_goals.json`.
- Отдельной «сеть нельзя на ручных» оговорки не требуется — сеть внутри той же кампании ведёт автостратегия.
- В `09_bidding_strategy.json` поле `"channel": "epk"`.

Всё остальное (триггеры фаз, коллтрекинг как gate для Фазы 3, ниши) применяется как для Поиска.

## Пакетные стратегии (№273)

**Пакетная стратегия** объединяет несколько однотипных ЕПК-кампаний в **один общий пул обучения**. Ключевое отличие от обычной стратегии:

| Параметр | Обычная стратегия | Пакетная стратегия |
|----------|-------------------|--------------------|
| Порог обучения | ≥10 конв/нед **по каждой РК** | ≥10 конв/нед **суммарно по пулу** |
| Область оптимизации | одна кампания | до **100 кампаний** в пакете |
| На что смотрит алгоритм | данные одной РК | данные всех РК пула вместе |

**Зачем это нужно.** Прямое решение проблемы «<10 конверсий/нед на отдельной кампании»:
- **Премиум и малые ниши** — конверсий мало, поодиночке кампании «голодают» по данным и не выходят из обучения.
- **Дробление по углам/сегментам** — когда одну цель ведут несколько ЕПК по разным углам, каждая набирает мало, а суммарно порог легко перекрывается.

**Рекомендация.** Как только у вас несколько ЕПК по разным углам/сегментам с **одной целью** — заводите их в **пакетную стратегию**, чтобы объединить данные и не «голодать». В `09_bidding_strategy.json` помечайте такие кампании общим значением `package_strategy_id` (у остальных оно `null`).

⚠️ **Пакетную стратегию MCP не заводит** — её создают в интерфейсе Директа. Заливка ставит кампаниям обычную стратегию Фазы 1, а объединение в пакет уходит в `10_launch_log.md` списком ручной работы. Поле `package_strategy_id` нужно именно для того, чтобы этот пункт не потерялся.

## Бюджеты: неделя как базовая единица (№255/№272/№277)

Базовая единица бюджета в Директе — **неделя** (минимум **300 ₽/нед**). Автостратегии живут именно на недельном бюджете.

| Тип бюджета | Когда применяется | Единица |
|-------------|-------------------|---------|
| **Недельный** (базовый, №255) | автостратегии, основной режим | неделя, от 300 ₽ |
| **Периодный** (№272) | флайты/акции на заданный срок | заданный период |
| **Дневной** (№277) | только ручные ставки на Поиске | сутки |

- **Автостратегии** («Максимум кликов», «Максимум конверсий», «Максимум прибыли») работают на **недельном** бюджете — дневной для них не применяется.
- Существующие примеры в этом файле (`недельный бюджет 5 000 ₽`) — это и есть базовая недельная единица.

## Оплата за конверсии — параметры (№249)

При «Максимум конверсий» **с оплатой за конверсии** списание идёт только за целевое действие. Жёсткие рамки алгоритма:

| Параметр | Значение |
|----------|----------|
| Окно атрибуции | **21 день** |
| Недельный бюджет | **≥ 10 × цена конверсии** |
| Цена конверсии | **≤ 50 000 ₽** |

**Практический вывод.** При цене конверсии **2 000 ₽** недельный бюджет — **от 20 000 ₽** (10 × 2 000). Меньше — алгоритм не разгонится и не выйдет из обучения. Считайте недельный бюджет от цены конверсии, а не наоборот.

## Особые случаи

### Один кампания всего
Делаем стратегию для неё одной, без сравнений. Гейт короткий.

### Без коллтрекинга совсем
Фаза 3 («Максимум конверсий») **невозможна**. Останавливаемся на Фазе 2 (ограничение средней цены клика). Прямо: «без коллтрекинга кампания не пойдёт дальше «Максимума кликов». Если в нише важны звонки (срочный спрос, B2B) — поставь коллтрекинг до запуска, иначе теряем 30-50% эффективности».

### Только РСЯ (экспертный вариант ЕПК)
Экспертный вариант ЕПК «только РСЯ»: сеть практически **никогда не ведём на ручных ставках и «Максимуме кликов»** — нужен «Максимум конверсий» с оплатой за конверсии и CPA-лимитом, иначе бюджет уйдёт на бот-площадки.

### Только МК (Мастер кампаний)
Предупреди: «МК — это backup-вариант, а не основной. Для бюджета >50к/мес рекомендую комбинаторную ЕПК (Поиск + сеть в одной РК) с эволюцией к «Максимум конверсий».

### Накопленные данные есть с прошлой кампании
Если у клиента уже >200 конверсий за 6 мес — можно **пропустить Фазу 1**: на старте сразу «Максимум конверсий» с CPA-лимитом по историческим. Редкий случай.

## Стиль работы

- **Не «правильная стратегия одна на всех».** Для каждой кампании своя.
- **Триггеры цифрами, не интуицией.** «Когда будет лучше» — не план. «10 конв/нед + CTR ≥4% две недели подряд» — план.
- **Коллтрекинг — gate-критерий.** Не идём в Фазу 3 без него.
- **Стартовая стратегия проста.** Чем больше параметров на старте — тем больше шансов, что один из них ошибочный.
