# Яндекс.Директ — генерация картинок через AI

`scripts/generate_creative_images.py` генерит картинки для комбинаторного объявления
(ЕПК) через OpenAI Images API (`gpt-image-1` / `dall-e-3`) на основе
`combined_ad.visual_concepts` из `08_creatives.json`. Это Шаг 8.5 пайплайна —
подробности по гейтам и требованиям Яндекса см. `references/rsya-creatives.md`.

## Когда использовать

- РСЯ есть в брифе (поле 5), Шаг 8 (объявления) уже сделан — есть `08_creatives.json`
  с заполненными `combined_ad.visual_concepts`.
- Нет дизайнера или нужен быстрый первый прогон креативов для теста гипотез.

## Когда НЕ использовать

- **UI-скриншоты продукта (`ui_mockup`)** — AI генерит интерфейсы ненадёжно, скрипт
  их даже не отправляет в OpenAI, а сразу помечает `needs_real_screenshot`. Нужен
  реальный скриншот от клиента.
- **Видео** — отдельный скрипт и отдельный reference: `references/video-generation.md`
  (`generate_creative_videos.py`, провайдер Replicate).
- **Лица реальных людей** — шаблоны промптов явно просят их не генерировать
  (`YANDEX_RULES` в `prompt_templates.py`), это не тот инструмент для UGC.

## Архитектура

```
scripts/
├── generate_creative_images.py   ← главный CLI
├── prompt_templates.py            ← 5 шаблонов промптов + IMAGE_SPECS (форматы/размеры)
├── brand_defaults.json            ← дефолты цвета/стиля бренда
└── validate_assets.py             ← проверка готовых картинок (и видео) под требования Директа
```

В рабочей папке кампании:

```
direct-campaigns/<slug>/
├── brand.json                     ← (опционально) переопределение бренда
├── 08_creatives.json              ← вход: combined_ad.visual_concepts; скрипт дописывает combined_ad.images
└── assets/
    ├── images/                    ← сгенерированные картинки: g{N}_{CID}_{FMT}.png
    ├── prompts/                   ← сохранённые промпты (для аудита): g{N}_{CID}_{FMT}.txt
    └── generation_log.json        ← лог последнего запуска (статус по каждой картинке)
```

`{N}` — номер группы (1-based), `{CID}` — id концепции (например `A`), `{FMT}` —
формат (`1x1` / `4x3` / `16x9` / `3x4`).

## brand.json — что туда положить

```json
{
  "product_name": "PlanFix",
  "primary_color": "#1E40AF",
  "accent_color": "#22C55E",
  "style_references": [
    "modern Russian e-commerce banners",
    "Yandex Market promo cards",
    "clean flat advertising design"
  ]
}
```

Если файла нет — берутся дефолты из `scripts/brand_defaults.json` (нейтральные
цвета-заглушки). Локальный `brand.json` в папке кампании имеет приоритет.

## 5 типов креативов

| Тип | Когда применяется | Формат по умолчанию |
|---|---|---|
| `product_offer` | Дефолт — крупное УТП + продукт/услуга. Срабатывает, если в `angle`/`notes` концепции нет других ключевых слов | 4:3 + 16:9 (+ 1:1 для первой концепции в списке) |
| `pain_split` | Split-screen «до/после»: в `angle`/`notes` встречаются «до/после», «до после» или «боль» | 4:3 + 16:9 (+ 1:1 для первой концепции) |
| `abstract_brand` | Брендовая композиция с коротким текстом: в `angle`/`notes` — «имидж» или «бренд» | 4:3 + 16:9 (+ 1:1 для первой концепции) |
| `social_proof` | Цифры/результат («200+ клиентов»): в `angle`/`notes` — «клиентов», «отзыв», «лет на рынке», «выполнено», «рейтинг» | 4:3 + 16:9 (+ 1:1 для первой концепции) |
| `ui_mockup` | Плейсхолдер — в `angle`/`notes` есть «скриншот», «интерфейс» или «ui». API не вызывается, нужен реальный скриншот от клиента | не генерируется (needs_real_screenshot) |

Тип можно задать явно полем `"type"` в концепции — тогда автоопределение по
ключевым словам не срабатывает (`detect_creative_type()` в `prompt_templates.py`).

Набор форматов не зависит от типа — он зависит от позиции концепции в
`visual_concepts` (первая концепция получает 3 формата — 4:3, 16:9, 1:1;
остальные — 2: 4:3, 16:9), если только в самой концепции не задано явное поле
`"formats"`. Итог ограничен лимитом ResponsiveAd — не больше 5 картинок на объявление.

## Форматы и размеры

OpenAI Images API умеет только квадрат и два прямоугольника
(`1024x1024` / `1536x1024` / `1024x1536`). Скрипт генерит в ближайшем поддерживаемом
размере, затем PIL делает resize + центральный crop до целевого размера под Директ:

| Формат | Размер OpenAI | → Целевой размер (Директ) |
|---|---|---|
| `1x1` | 1024×1024 | 1080×1080 |
| `4x3` | 1536×1024 | 1440×1080 |
| `16x9` | 1536×1024 | 1920×1080 |
| `3x4` | 1024×1536 | 1080×1440 |

Если PIL не установлен — картинка остаётся в исходном (OpenAI) размере, скрипт
выдаёт `WARN`, и такую картинку почти наверняка завернёт `validate_assets.py`.

## Workflow

### Шаг 1. Ключ OpenAI

```bash
python -m scripts.manage_credentials set openai
```

или переменная окружения `OPENAI_API_KEY`.

### Шаг 2. Dry-run (без вызовов API, бесплатно)

```bash
python -m scripts.generate_creative_images --workspace <path> --dry-run
```

Для каждой картинки в `assets/prompts/<name>.txt` сохранится готовый промпт —
прочитай 1-2, оцени качество и соответствие УТП, прежде чем тратить деньги.

### Шаг 3. Тест на одной концепции

```bash
python -m scripts.generate_creative_images --workspace <path> --concept A
```

`--concept` фильтрует по id концепции (например `A`), `--group` — по номеру
группы (1-based), если нужно ограничиться одной группой из нескольких.

### Шаг 4. Полный прогон

```bash
python -m scripts.generate_creative_images --workspace <path>
```

Сгенерит все картинки по плану (до 5 на объявление), допишет относительные пути
в `combined_ad.images` в `08_creatives.json`. Уже существующие файлы по умолчанию
пропускаются (`skip`).

### Шаг 5. Перегенерация

```bash
python -m scripts.generate_creative_images --workspace <path> --concept A --force
```

`--force` перегенерит существующие картинки поверх. Модель можно сменить
флагом `--model gpt-image-1` (дефолт) или `--model dall-e-3`.

### Шаг 6. Валидация

```bash
python -m scripts.validate_assets --workspace <path>
```

Проверяет реальные размеры/вес/формат каждого файла в `assets/images/` под
требования Директа. Отчёт — `assets/validation_report.json`, exit code 1 при фейлах.

## Безопасные зоны

Держи текст, логотип и ключевой объект внутри центральных 80% холста —
отступ ≥10% от каждого края, а сам текст не более 20% площади изображения.
Это зашито прямо в промпт (`YANDEX_RULES` в `prompt_templates.py`), а не
только рекомендация «для красоты»:

- **Служебные наложения площадок РСЯ.** На части плейсментов Директ накладывает
  на картинку метку «Реклама», кнопки действия и другие служебные элементы —
  если важный текст/лого стоит впритык к краю, его может перекрыть.
- **Модерация.** Правила Директа по текстово-графическим объявлениям запрещают
  текст на креативе свыше ~20% площади, CAPS длиннее 4 символов и больше
  одного восклицательного знака (см. `references/yandex-direct-specs.md`) —
  промпт-шаблоны это уже учитывают, но при ручной правке промпта проверяй сам.

## Какая модель лучше

| Модель | Плюсы | Минусы | Когда брать |
|---|---|---|---|
| **gpt-image-1** | Хорошо рендерит текст и брендинг, понимает «layout» | Дороже, медленнее | Дефолт. Для УТП с текстом на баннере, абстрактных композиций с typography. |
| **dall-e-3** | Дешевле, быстрее | Хуже с текстом, может перевирать буквы | Если бюджет важнее, или для split-screen где меньше типографики. |

## Промпт-инженерия (что важно)

### Что работает
- **Указывать стилевые ориентиры** (`style_references` в brand.json — например
  «modern Russian e-commerce banners», «Yandex Market promo cards»)
- **Конкретные цвета в HEX** — модель понимает
- **«No people. No realistic photos.»** — если хочешь vector/flat
- **Aspect ratio** в промпте — даже если задаёшь через `size`, дублируй в тексте
- **«DO NOT include»** блок — модель его слушает

### Что НЕ работает
- Названия реальных конкурирующих брендов в промпте («как у Х, но лучше») —
  модель боится копирайта
- Точное расположение всех элементов — модель не пиксель-перфект
- Сложные UI mockup — даже gpt-image-1 ломается на интерфейсах (см. `ui_mockup`
  выше — поэтому для этого типа скрипт вообще не дёргает API)
- Картинки с >10 словами текста — текст становится мусором (лимит Директа — тоже
  ориентировочно 10 слов, см. чек-лист модерации)

## Чек-лист готовности к запуску

- [ ] Ключ OpenAI сохранён (`python -m scripts.manage_credentials set openai`
      или env `OPENAI_API_KEY`)
- [ ] Сделан `--dry-run` — промпты в `assets/prompts/` выглядят разумно
- [ ] Сделан тест на 1 концепции (`--concept A`) — результат устраивает
- [ ] Полный прогон — все картинки сгенерены в `assets/images/`
- [ ] `python -m scripts.validate_assets --workspace <path>` — 0 ошибок
- [ ] Ручной ревью результатов (текст читаем, лого не обрезано, бренд-цвета на месте)
