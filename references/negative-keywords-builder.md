# Negative Keywords Builder — три уровня минусов и кросс-минусация

Используется на Шаге 6 пайплайна (после структуры кампаний). Задача — **предотвратить две главные ошибки бюджетного слива**: нерелевантный трафик (информационные запросы, конкуренты, общий шум) и каннибализация между собственными кампаниями.

## Главный принцип — три уровня минусов

Минусы — это **не одна большая свалка слов**, а несколько уровней, каждый со своей логикой. Важно: нативных «уровней» минус-слов в Директе **три** — **кампания / группа / ключ** (справка Директа №288). Отдельного «аккаунт-уровня» минус-слов в Директе **нет** — переиспользуемый набор реализуется через **Библиотеку минус-фраз** (наборы): до 30 наборов на аккаунт, к кампании или группе можно привязать до 3 наборов.

| Уровень | Куда применяется | Что туда идёт |
|---------|------------------|---------------|
| **Аккаунт** (НЕ нативный уровень Директа, а конструкция скилла — набор **Библиотеки минус-фраз**, привязываемый ко всем кампаниям бренда) | Все кампании бренда | Универсальный мусор: бесплатно, скачать, своими руками, торрент, википедия |
| **Кампания (Поиск)** | Только поисковые кампании | Информационные запросы, виды деятельности «как сделать», синонимы из других ниш |
| **Кампания (сети)** | Сетевая часть той же ЕПК | Не текстовые минусы — площадки и аудитории. Текстовых минусов для сетей почти нет |
| **Кросс-минусы** | Между кампаниями | Сужающие слова других кампаний (премиум-кампания минусует +срочно) |

## Лимиты минус-фраз (числа)

Жёсткие ограничения Директа (справка №287) — держим в голове при сборке уровней:

- **Уровень кампании:** суммарно **20 000 символов** без пробелов на весь набор минус-фраз кампании.
- **Уровень группы:** **4096 символов** на набор минус-фраз группы.
- **Одна минус-фраза:** не более **7 слов**.

Если упираемся в лимит кампании (20 000) — часть универсального мусора выносим в **набор Библиотеки минус-фраз** (лимиты Библиотеки — ниже, справка №288), так как набор Библиотеки считается отдельно от собственных минус-фраз кампании.

## Что НЕ делаем

- Минусы из обновлений «по ходу работы» — это уже работа с активной кампанией, **не задача этого скилла**.
- Минус-площадки РСЯ — отдельный механизм, требует статистики кампании.
- Минус-аудитории (look-alike exclusions) — стратегические настройки.

## Вход

1. **Структура кампаний** — `05_campaign_structure.json` (Шаг 5). Каждая кампания привязана к сужающему слову.
2. **Все ключи** — `04_keys_search_obligatory.csv`, `04_keys_search_vch.csv`, `04_keys_rsya.csv` из `wordstat-filter` (Шаг 4).
3. **Тип ниши** — обычная / срочный спрос / премиум / B2B SaaS / массовые. Определяется по контексту брифа. Для базового минус-листа.
4. **Сужающие слова** всех кампаний — из `00_brief.md` (поле 7) — для кросс-минус-матрицы.

Если входа нет:
```
Чтобы собрать минусы:
1. Список кампаний (имена + ключевое сужающее) — или ссылка на masks.json / keys_*.csv?
2. Тип ниши: обычная / срочный спрос / B2B / премиум?
3. Каналы: Поиск / РСЯ / оба?
```

## Фаза 1. Аккаунт-уровень — универсальный минус-лист

Берём универсальный набор + специфический по нише. См. «Базовые минус-листы» ниже.

Реально это **набор Библиотеки минус-фраз** (справка Директа №288: до 30 наборов на аккаунт, до 3 наборов на кампанию/группу, до 4096 символов на один набор), который привязывается к кампаниям бренда. «Аккаунт-уровень» (= набор Библиотеки минус-фраз) — рабочее название конструкции скилла, а не отдельная сущность Директа. Файл-артефакт `06_negative_keywords_account.csv` остаётся, но при заливке он ложится в набор Библиотеки.

Идёт в `06_negative_keywords_account.csv` — применяется на всех будущих кампаниях бренда. Применять однократно при настройке аккаунта.

## Фаза 2. Кампания-уровень — Поиск

Поиск пускает только ключи с сужающим словом + общим. Минусы здесь — для **информационных и обучающих** запросов, проскальзывающих через сужающее:

**Типовые поисковые минусы:**
- Вопросительные в начале: `как`, `что такое`, `чем отличается`, `почему`, `зачем`
- Обучающие: `обучение`, `курсы`, `видео урок`, `мастер класс`, `пошагово`
- Информационные: `отзывы` (если у нас нет страницы с отзывами), `форум`, `обзор`
- Сегментные пересечения (см. отраслевые шаблоны)

Идёт в `06_negative_keywords_search.csv` — только для поисковых кампаний.

## Фаза 3. Кампания-уровень — РСЯ

В РСЯ текстовые минусы работают **иначе**. Минусы здесь — это часто:
- Площадки (минус-площадки) — собираются на основе статистики, не до запуска
- Аудитории-исключения — настраиваются на уровне таргетинга

Что в текстовые минусы РСЯ всё же положить:
- Только узкие, гарантированно нерелевантные термины (см. ниши)
- Никаких «общих информационных» — РСЯ работает по интересам/площадкам

`06_negative_keywords_rsya.csv` — обычно короткий список, 10-30 слов.

## Фаза 4. Кросс-минусация между кампаниями (главная фаза)

Если 3 кампании с сужающими `+премиум`, `+срочно`, `+межгород` — между ними строим матрицу:

| Кампания / минусует | Премиум | Срочно | Межгород |
|---------------------|---------|--------|----------|
| **Премиум** | — | +срочно, +быстро, +15минут | +межгород, +регион |
| **Срочно** | +премиум, +элитный, +эксклюзив | — | +межгород, +регион |
| **Межгород** | +премиум, +элитный, +эксклюзив | +срочно, +быстро, +15минут | — |

**Что это значит:**
- Каждая кампания минусует сужающие слова **всех остальных кампаний** + их языковые синонимы
- Без этого: пользователь ищет «эвакуатор премиум срочно» → попадает в обе кампании «премиум» и «срочно» → они воюют в аукционе → CPC растёт на 30-50%, статистика разъезжается

Артефакт: `06_cross_minus_matrix.md` + `06_negative_keywords_cross.csv` с раскладкой «кампания → минусы».

## Точное соответствие фразе как альтернатива кросс-минусации

Оператор **точного соответствия фразе** (справка Директа №285) позволяет развести пересекающиеся запросы между группами **без** ручной кросс-минус-матрицы — или в дополнение к ней. Ключ в режиме точного соответствия фразе ловит только сам запрос (в заданном порядке слов и без «добора» лишними словами), поэтому пользователь с запросом «эвакуатор премиум срочно» уже не проваливается одновременно в группу «премиум» и группу «срочно».

Это альтернатива/усиление **Фазы 4** для случаев, когда кросс-матрица становится громоздкой (много кампаний, см. «Много кампаний (5+)»): вместо матрицы N×N сужающих можно зафиксировать ключи точным соответствием фразе и снять большую часть пересечений структурно. На практике оба механизма комбинируются — точное соответствие фразе снимает основную массу коллизий, а кросс-минусы добивают остаточные языковые синонимы.

## Фаза 5. Финальная сборка + дедупликация

1. Объединяем три уровня в `06_negative_keywords.json`. Ключи объекта `campaigns` — **`campaign_key` из `05_campaign_structure.json`**, не человеческое имя угла: по нему заливка находит, какие минусы отдать какой кампании.

```json
{
  "account_level": ["бесплатно", "скачать", "своими руками", ...],
  "campaigns": {
    "premium": {
      "search": ["обучение", "как нарисовать", ...],
      "rsya": [],
      "cross_minus_from_other_campaigns": ["+срочно", "+быстро", "+15минут", "+межгород"]
    },
    "srochno": {
      "search": ["видео урок", "история эвакуатор", ...],
      "rsya": [],
      "cross_minus_from_other_campaigns": ["+премиум", "+элитный", "+эксклюзив", "+межгород"]
    }
  },
  "total_minus_words": 247
}
```

2. **Дедупликация:** если минус-слово есть на уровне аккаунта — убираем с уровней кампаний (избыточно). Упрощает чтение и предотвращает «двойное минусование».

3. Сводный `06_negative_summary.md` с раскладкой по уровням и обоснованиями.

## Как эти уровни ложатся в заливку

MCP **не умеет** Библиотеку минус-фраз, поэтому «аккаунт-уровень» — конструкция скилла, а не отдельная сущность в Директе. При заливке три уровня схлопываются в два нативных:

| Куда уходит | Что складывается |
|---|---|
| Минус-фразы **кампании** (`campaigns_add.negative_keywords`) | `account_level` + `campaigns[<campaign_key>].search` + `campaigns[<campaign_key>].rsya` + `cross_minus_from_other_campaigns`, после дедупликации. В ЕПК Поиск и сети — одна кампания, поэтому берутся обе группы минусов |
| Минус-фразы **группы** (`adgroups_add.negative_keywords`) | Узкие минусы группы из `08_creatives.json` |

**Лимиты, которые надо проверить до вызова:** кампания — 20 000 символов без пробелов, группа — 4096, каждая фраза ≤7 слов.

При переполнении лимита кампании режь по приоритету: сначала `account_level` (он универсальный и продублирован в других кампаниях), затем кросс-минусы, в последнюю очередь поисковые. Вынесенное записывай в `10_launch_log.md` как «завести набором Библиотеки минус-фраз вручную» — до 30 наборов на аккаунт, до 3 на кампанию.

Считает и предупреждает `scripts/preflight.py`.

## Базовые минус-листы по нишам

### Универсальные (для всех ниш) — аккаунт-уровень

30-40 минусов в каждый аккаунт независимо от ниши.

**Самостоятельность / DIY:**
- `своими руками`, `сам`, `самостоятельно`, `делаем сами`
- `как сделать`, `как сделать своими руками`, `мастер класс`, `пошагово`

**Бесплатное:**
- `бесплатно`, `даром`, `халява`, `без оплаты`, `без денег`
- `скачать`, `скачать бесплатно`, `торрент`, `пиратская версия`

**Образовательное:**
- `курсы`, `обучение`, `тренинг`, `видеоурок`, `гайд`, `туториал`
- `реферат`, `курсовая`, `дипломная`, `учебник`, `википедия`

**Развлекательное:**
- `фильм`, `сериал`, `аниме`, `мультфильм`, `песня`, `mp3`
- `прикол`, `мем`, `шутка`, `пост`, `вконтакте`, `тикток`

**Работа / вакансии:**
- `работа`, `вакансия`, `вакансии`, `подработка`, `сотрудник`
- `требуется`, `найти работу`, `резюме`, `hh`, `хедхантер`

**Маркетплейсы (если мы не на них):**
- `авито`, `авито.ру`, `озон`, `ozon`, `wildberries`, `вб`
- `яндекс маркет`, `али`, `алиэкспресс`, `aliexpress`

**Б/У и подержанные:**
- `б у`, `б/у`, `бу`, `подержан`, `вторичный`, `с пробегом`

### Срочный спрос — Поиск-уровень

Дополнения для эвакуатор, такси, аварийный сантехник, замки, ветеринар скорая.

**Информационные:**
- `как вызвать`, `куда звонить`, `что делать`, `куда обращаться`
- `статья`, `закон`, `регулирование`, `штраф`, `документы`

**Образовательные:**
- `профессия`, `обучение на эвакуаторщика`, `права категории`, `категория c`
- `как стать`, `работа эвакуаторщиком`

**Игры/детское:**
- `lego`, `симулятор`, `игрушка`, `детский`, `gta`, `pixel`, `minecraft`, `roblox`

**Видео/контент:**
- `видео`, `youtube`, `обзор`, `тест-драйв`, `как работает`

**НЕ минусовать в срочном спросе:**
- ❌ `срочно`, `быстро`, `сейчас` — это наоборот ключевые слова срочного спроса
- ❌ `ночью`, `круглосуточно` — это сценарии
- ❌ `доставка` (если есть автомобильная категория) — это услуга

### Премиум-сегмент — Поиск-уровень

**Дешёвое / массовое:**
- `дешево`, `дёшево`, `недорого`, `бюджетно`, `эконом`, `по акции`
- `скидка`, `распродажа`, `купон`, `промокод`, `выгодно`

**Массмаркет:**
- `массмаркет`, `икеа`, `ikea`, `аналог`, `похожий на`
- `подобие`, `копия`, `реплика`, `имитация`, `подделка`

**Бюджетные сегменты:**
- `студенческий`, `молодёжный`, `до 5 000`, `до 10 000` (для премиума с чеком 100к+)
- `на свадьбу не дорого`, `подарок до 1000`

**НЕ минусовать в премиуме:**
- ❌ `вип`, `vip`, `luxury`, `lux` — ключевые слова премиума
- ❌ `эксклюзивный`, `элитный` — наши

### B2B SaaS — Поиск-уровень

**B2C-намерения:**
- `для себя`, `личный кабинет` (когда нацелены на бизнес)
- `физическое лицо`, `физлицо`, `личное использование`

**Не-IT категории:**
- `crm для одноклассников`, `crm система отношений` (личностные)
- `программа` без указания области (если есть пересечения)

**Конкретные пересечения (B2B salon SaaS):**
- `мастер маникюра`, `парикмахер` (без `для`) — если кампания продаёт CRM **владельцам**
- `клиент салона`, `как записаться` — это B2C, не наш сегмент

**Программирование / разработка:**
- `написать свой`, `сделать crm`, `шаблон crm`, `php`, `python`, `1с программист`
- `исходный код`, `open source`, `гитхаб`, `github`

**НЕ минусовать в B2B SaaS:**
- ❌ `альтернатива X` — часто хороший entry для отстройки
- ❌ `интеграция`, `api` — бизнес-термины
- ❌ `тариф`, `подписка` — покупка-намерения

### Ручная работа / на заказ — Поиск-уровень

**Принт-сегмент (главная отстройка):**
- `постер`, `модульная картина`, `печать на холсте`, `печать на полотне`
- `репродукция`, `тиражный`, `массовая печать`, `принт`, `постер икеа`

**Цифровое:**
- `digital`, `файл`, `psd`, `png`, `jpg`, `шаблон ms office`
- `сгенерировать ai`, `нейросеть`, `midjourney`, `stable diffusion`

**Образовательное:**
- `как нарисовать`, `научиться рисовать`, `курсы живописи`, `школа искусств`
- `мастер класс по рисованию`, `онлайн школа`

**Готовые наборы:**
- `алмазная мозаика`, `алмазная вышивка`, `раскраска по номерам`, `вышивка крестом`
- `набор для творчества`, `детский набор`

**НЕ минусовать в ручной работе:**
- ❌ `на заказ`, `подзаказ`, `по фото` — наши слова
- ❌ `авторский`, `художник`, `ручной` — наши маркеры

### Массовые услуги — Поиск-уровень

**Регулярные:**
- `сделать самому`, `мастерская дома`, `dyi`
- `онлайн`, `удалённо` (если услуга физическая)
- `обучение`, `курсы`

**Конкретные пересечения:**
- Для пиццы: `рецепт`, `домашняя пицца`, `тесто для пиццы`
- Для ремонта: `замена своими руками`, `инструкция`, `видеоурок`
- Для уборки: `средство для уборки`, `пылесос купить`, `химия для уборки`

### Принцип использования

1. Фаза 1 (аккаунт-уровень) — берём «Универсальные» полностью.
2. Фаза 2 (Поиск-уровень) — берём раздел ниши + добавляем кросс-минусы (Фаза 4).
3. Если ниша из нескольких типов (премиум + ручная работа) — берём из обоих, дедуплицируем.
4. Маркетолог может добавлять/удалять. Стартовая точка, не догма.

### Анти-паттерны

- **Не минусовать на аккаунт-уровне то, что зависит от ниши.** Минус `мастер` корректен для CRM-кампании, но абсурден для аккаунта салона мастеров.
- **Не минусовать ключевые слова собственных гипотез.** Двойная проверка: если минус совпадает с сужающим — ошибка.
- **Не лепить только русские варианты.** Минусуем `wildberries` — добавляй `вб`, `wb`, `вайлдбериес`. Покрытие важнее краткости.
- **Не считать минусы готовыми.** Через 2 недели работы — отчёт «Поисковые запросы» в Метрике и добавляем мусор (это lifecycle).

## Особые случаи

### Одна кампания
Кросс-минусации нет (минусовать некого). Только аккаунт + Поиск/РСЯ. В `06_negative_summary.md`: «1 кампания, кросс-минусы не применимы».

### Две кампании
Простой случай: каждая минусует сужающие другой. Матрица 2×2.

### Много кампаний (5+)
Кросс-минусы громоздкие — каждая может минусовать 10-20+ слов. Норма, не пугайся. Но если две кампании имеют слишком близкие сужающие («+премиум» и «+элитный»), это **один угол, не два**. Маркетологу: «углы 1 и 2 слишком близки — объединить?» Возвращаем на Шаг 5 (`campaign-structure`) и поправляем структуру.

### Срочный спрос — особая логика
Кросс-минусация **усиленная**: нельзя пропустить ни одной маски, иначе высокая стоимость клика наказывается дважды. Минусуем не только сужающие, но и языковые синонимы — даже неочевидные («15минут» = «полчаса» = «момент» — все варианты в кросс-минусах для не-скоростной кампании).

### B2B SaaS — отдельная категория минусов
Большой класс — **B2C-намерения**. Кампания «CRM для салонов» должна минусовать `мастер`, `мастер маникюра` (если не своя сегментная кампания), `онлайн запись для клиентов` (это для клиентов салонов, а не салонов).

## Стиль работы

- **Минусы — дисциплина, не «попозже добавим».** Старт без минусов = 30-50% бюджета в первую неделю.
- **Не путать уровни.** Аккаунт = постоянный. Кампания = под конкретный тип. Кросс = между нашими.
- **Кросс-минусы — не выбор, а гигиена.** Без них аукцион сам с собой воюет.
- **Не минусовать сужающие в своей же кампании.** «Премиум» минусует «срочно», но НЕ «премиум» внутри себя.
