# Frequency Calculator — расчёт необходимой суммарной частотности

Используется на Шаге 2 пайплайна (между масками и сбором семантики). Задача — **точно ответить на два вопроса**:

1. Сколько суммарных показов в месяц нужно собранной семантике, чтобы потратить бюджет с заданной CTR?
2. Если семантика уже собрана — хватает ли её, нужно ли расширять?

Без этого расчёта легко уйти в крайности: собрать 50 запросов на бюджет, который требует 500 (кампания недогружена), или 2000 запросов на бюджет, на котором 80% не открутится никогда.

## Что НЕ считаем

- **РСЯ** — другая модель (показы дешевле, CTR ниже, частотность ≠ маска успеха). Для РСЯ — другие ориентиры.
- **Автостратегии с оплатой за конверсии** — модель кардинально иная, частотность управляется алгоритмом.
- **Мастер кампаний** — то же. Скажи маркетологу прямо: «расчёт частотности здесь не работает».

Если стратегия предполагает только РСЯ/МК — скилл сообщает «расчёт не применим» и завершается без артефакта.

## Главный принцип

Формула простая, нюансы — в **бюджете** (берём именно поиск, не весь) и в **CPC** (приоритет — прогноз через MCP, не справочник).

## Вход

1. **Бюджет на поиск** (₽/мес). Не общий! Если в `00_brief.md` (поле 4) «80к/мес», а из поля 5 «60% поиск, 40% РСЯ» — берём 60% × 80к = 48к на поиск.

2. **Оценка CPC** (₽/клик). Источники в порядке достоверности:
   - **(приоритет 1) Историческая AvgCpc** — если в аккаунте есть похожие кампании с открученным трафиком (`report_campaign`, `LAST_30_DAYS`). Реально списанные деньги — золотой стандарт. См. `mcp-account-integration.md` Use case 3.
   - **(приоритет 2) Живой аукцион** — `keywordbids_get`. Реальная списываемая цена клика (`Price`) по ключам, которые УЖЕ есть в аккаунте: ключи похожих кампаний из аудита (Use case 1). Парсится скриптом `scripts/forecast_cpc.py`. Ничего не меняет в аккаунте и не требует расхода бюджета.
   - **(приоритет 3) Прогноз по своим маскам** — `forecast_bids`. Вилка цены клика по произвольным фразам **без создания кампании**. Работает, когда в аккаунте вообще ничего нет. Недоступен в режиме прокси Click.ru.
   - **(приоритет 4) Справочная таблица** (см. ниже) — категории ниш + региональные коэффициенты. Фолбек, когда MCP недоступен.
   - **(override в любой момент) Маркетолог.** Если сам говорит «знаю, что у нас CPC ~700₽ из опыта прошлых кампаний» — берём, помечаем `from: marketer`.

3. **Оценка CTR** (%). Дефолт **5%** для поиска. Если у маркетолога есть статистика прошлых кампаний — берём её.

4. **Фактическая суммарная частотность** (опц.) — для сравнения с расчётной потребностью.

Если входа нет — задай маркетологу один блок (**про CPC не спрашиваем** — это работа прогноза):

```
Чтобы посчитать необходимую частотность, мне нужно:
1. Бюджет НА ПОИСК в месяц (не общий, а доля для поиска): ?
2. Регион показа (для оценки CPC по аукциону Direct API): ?
3. Маски уже собраны (есть `01_masks.json` от mask-builder)? Если в аккаунте есть похожие кампании — возьму CPC по их живому аукциону; если нет — прогноз по маскам, и уже потом дефолт по нише.
4. (опц.) Если собрана семантика — суммарная частотность, сравню.
```

## Формула

```
Клики_в_месяц = Бюджет_поиск ÷ CPC
Показы_в_месяц = Клики ÷ CTR
Необходимая_частотность = Показы × 2  (запас на погрешность)
```

Пример (картины ручной работы, 30к на поиск, CPC 200₽, CTR 5%):
- Клики = 30 000 ÷ 200 = **150 кликов/мес**
- Показы = 150 ÷ 0.05 = **3 000 показов/мес**
- С запасом ×2 = **6 000 показов/мес** — минимум суммарной частотности всех запросов в семантике.

## Фаза 1. Определение CPC

Идём сверху вниз — берём первый источник, который реально доступен.

### Приоритет 1 — историческая AvgCpc (если есть похожие кампании с трафиком)

Если аудит (Use case 1) нашёл в аккаунте семантически близкие кампании с `Statistics.Clicks > 0`:
```
mcp__yandex-direct__yandex_direct_report_campaign({ campaign_ids: [...], date_range: "LAST_30_DAYS" })
```
Берём `AvgCpc` (микро ÷ 1 000 000 = ₽). Помечаем: `from: history (campaign <id>, LAST_30_DAYS)`. Это самый достоверный источник — реально списанные деньги.

### Приоритет 2 — живой аукцион по ключам аккаунта

Реальные цены аукциона по ключам, которые **уже заведены в аккаунт**: берём `KeywordId` похожих кампаний из аудита (`keywords_get`, Use case 2) и дёргаем аукцион. Аккаунт при этом не меняется.

```
mcp__yandex-direct__yandex_direct_keywordbids_get({
  keyword_ids: [<id1>, <id2>, ...],     // или campaign_ids: [...]
  include_auction: true
})
```

Ответ объёмный (~44 позиции аукциона на ключ) — **не парси вручную**. Сохрани в `<workspace>/_keywordbids_raw.json` и прогони:
```
python -m scripts.forecast_cpc --input _keywordbids_raw.json --region-factor <множитель из брифа>
```
Скрипт берёт `Price` (списываемую цену, НЕ `Bid`) на трёх объёмах трафика и считает медиану по ключам:
- `base` = Price @ TrafficVolume ~75 (хорошая видимость без переплаты за топ)
- `pessimistic` = Price @ TrafficVolume ~100 (верх премиум-блока)
- `optimistic` = Price @ TrafficVolume ~62 (нижняя граница показа)

Эти три значения прямо ложатся в три сценария Фазы 2. Помечаем: `from: live-auction (N ключей, дата)`.

### Приоритет 3 — прогноз по своим маскам

Если похожих кампаний в аккаунте нет, берём прогноз по маскам напрямую — **создавать ничего не нужно**:

```
mcp__yandex-direct__yandex_direct_forecast_bids({
  phrases: [<до 100 масок из 01_masks.json>],
  region_ids: [<из брифа>]
})
```

По каждой фразе вернётся вилка цены клика и прогноз трафика. В три сценария Фазы 2 ложится так:

- `optimistic` = медиана `cpc_guarantee_min` по фразам
- `base` = медиана `cpc_guarantee_max`
- `pessimistic` = медиана `cpc_premium_min` (вход в спецразмещение)

Заодно приходят `shows_per_month` и `clicks_per_month` — их можно сверить с расчётной потребностью в частотности, не дожидаясь Шага 3. Суммы в валюте аккаунта, не в микроединицах. Помечаем: `from: forecast (N фраз, дата)`.

🚫 **В режиме прокси Click.ru прогноз недоступен** — он живёт в Live API v4, которому нужен OAuth-токен Яндекса. Инструмент вернёт понятную ошибку: это не поломка конфигурации, а устройство API. В этом случае переходим к приоритету 4.

> `scripts/forecast_cpc.py` умеет звать аукцион и сам: `python -m scripts.forecast_cpc --keyword-ids 1,2,3` при `YANDEX_DIRECT_TOKEN` в окружении — для запуска вне MCP-сессии.

### Приоритет 4 — справочник CPC (фолбек)

Если MCP недоступен или прогноз не отработал (например режим Click.ru, а похожих кампаний в аккаунте нет):
   - Определи тип ниши по контексту
   - См. справочник CPC ниже → базовый CPC категории
   - Применяй региональный коэффициент
   - Помечаем: `from: defaults-table (niche=Категория Б, region_factor=0.6)`

### Override от маркетолога

Скилл сам **не запрашивает** CPC — только принимает, если маркетолог дал из своего опыта (`from: marketer`). Может перебить любой источник выше.

### Если ничего не сработало

Стоп. Маркетологу: «не могу прикинуть CPC ни по одному источнику. Дай либо доступ к Direct API, либо подтверди категорию ниши, либо назови ориентир». Не выдумывай.

**Источник всегда отмечен в артефакте** — критично, маркетолог смотрит, насколько цифре доверять.

## Фаза 2. Расчёт

1. Формула. Округляем до сотен (3 247 → 3 200) — не делаем вид, что точность до клика.
2. ×2 запас на погрешность.
3. Три сценария — **оптимистический** (CPC × 0.7), **базовый** (CPC), **пессимистический** (CPC × 1.5).

Пример вывода:

```
| Параметр | Значение |
|----------|----------|
| Бюджет на поиск | 30 000 ₽/мес |
| CPC | 200 ₽ (источник: live-auction, медиана Price по 8 ключам в Мск+СПб) |
| CTR | 5% (default) |
| Клики/мес | 150 |
| Показы/мес | 3 000 |
| × 2 запас | **6 000 показов/мес — необходимая суммарная частотность** |

| Сценарий | CPC | Клики | Показы (×2) |
|----------|-----|-------|-------------|
| Оптимистический | 140 ₽ | 215 | 8 600 |
| Базовый | 200 ₽ | 150 | 6 000 |
| Пессимистический | 300 ₽ | 100 | 4 000 |
```

## Фаза 3. Сравнение с фактической семантикой

Если есть `01_masks.json` или вывод сбора с суммарной частотностью:

1. `actual_sum = сумма всех показов собранных запросов`.
2. Сравниваем с базовым (×2):
   - `actual_sum < необходимая × 0.5` → **критически не хватает**. Предлагаем расширения.
   - `actual_sum < необходимая` → **не хватает**, но не критично. Точечные расширения.
   - `actual_sum ∈ [необходимая, необходимая × 1.5]` → **в норме**.
   - `actual_sum > необходимая × 1.5` → **с запасом**, можно фильтровать НЧ-хвост.

3. Конкретные предложения расширений (если не хватает):
   - «Добавить смысловые синонимы для колонки Б — товарозаменители: `панно`, `постер авторский`, `холст`».
   - «Расширить географию: добавить регионы N, M».
   - «Снизить порог 150 до 100 — потеряем дисциплину, но наберём 30% хвоста».
   - «Подключить РСЯ — там объём другой, формула не работает, но трафик будет».
   - **Никогда** не предлагай «расширить сужающие слова» — это размывает гипотезу.

## Справочник CPC по нишам Рунета (фолбек)

⚠️ Это **фолбек**, не первичный источник. Сначала — реальные данные (история открутки, живой аукцион `keywordbids_get`, прогноз `forecast_bids`). Справочник используется когда:
- MCP недоступен (нет токена, нет MCP-сервера)
- Режим прокси Click.ru (прогноз недоступен), а похожих кампаний в аккаунте нет
- Оценка нужна до сбора масок — как первая прикидка

### Категория А: Обычные тематики — базовый CPC ~200 ₽
Низкая или средняя конкуренция, понятный продукт, чек 1-30к ₽.
- Интерьерные товары: картины, мебель на заказ, текстиль
- Подарки и handmade: торты, букеты, авторская керамика
- Услуги мастеров: маникюр, парикмахер, фотограф, репетитор
- Косметология/SPA массового сегмента
- Локальные услуги: химчистка, клининг, доставка
- Хобби-сегмент: цветы, рукоделие, домашние животные

**Диапазон:** 100-300 ₽; **Целевой CTR:** 5-8%

### Категория Б: Среднеконкурентные — базовый CPC ~500 ₽
Высокий чек, активная конкуренция.
- B2B SaaS массовый: CRM салонные, бухгалтерия, кассы
- Премиум товаров: дизайнерская мебель, ювелирка, элитная одежда
- Образование: курсы программирования, IT, MBA, языковые
- Туризм: отели, авиабилеты, экскурсии
- Спорт: фитнес-клубы, персональные тренеры
- Эвакуатор/экстренные услуги в крупных городах
- Ремонт техники и квартир

**Диапазон:** 300-700 ₽; **Целевой CTR:** 5-10%

### Категория В: Высококонкурентные — базовый CPC ~1500 ₽
Большие чеки, агрегаторы доминируют.
- Юридические услуги
- Медицина (клиники, имплантация, ЭКО)
- Недвижимость (новостройки, элитная вторичка)
- Автокредиты, ипотека, рефинансирование
- Страхование (КАСКО, ОСАГО)
- B2B SaaS корпоративный (ERP, BI, бухгалтерия для крупного бизнеса)
- Микрозаймы (с ограничениями Директа)

**Диапазон:** 800-2 500 ₽; **Целевой CTR:** 3-7%

### Категория Г: Экстремально высокие — базовый CPC ~3000+ ₽
Узкие премиум-ниши.
- Недвижимость премиум (пентхаусы, загородные 50М+)
- Импорт авто, спецтехника
- Юридические услуги по уголовным делам, арбитраж
- Медицина-флагман (онкология, кардиохирургия)
- Финансы для high-net-worth (private banking)

**Диапазон:** 2 000-5 000+ ₽; **Целевой CTR:** 3-5%

### Корректировки по геолокации

Базовые CPC — для Москвы. Корректируем:

| Город | Множитель |
|-------|-----------|
| Москва | × 1.0 |
| СПб | × 0.85 |
| Города-миллионники (Казань, Нижний, ЕКБ, Новосиб) | × 0.5-0.7 |
| Региональные центры (500к-1M) | × 0.3-0.5 |
| Малые города (<500к) | × 0.2-0.3 |
| Вся РФ (микс) | × 0.7-0.8 |

### Сезонные корректировки

В пиковые недели CPC растёт:
- Чёрная пятница / Новый год: ×1.5-2 для подарочного сегмента
- 14 февраля, 8 марта: ×1.3-1.7 для подарков, цветов, ресторанов
- Сентябрь (back-to-school): ×1.2-1.5 для канцелярии, курсов, детских товаров
- Майские/летние каникулы: ×1.2-1.5 для туризма
- Дача-сезон (апрель-май): ×1.3-1.5 для садовой техники

### Что говорить маркетологу

```
CPC: 200 ₽
Источник: defaults-table → Категория А (обычные тематики, ниша «картины ручной работы»)
Корректировки: Москва+СПб = × ~0.95 → итоговая 190 ₽, округлено до 200 ₽
```

### Ниша не находится

1. Маркетологу: «нишу не нашёл в справочнике, ставлю Категорию Б (500 ₽) как осторожный дефолт — проверь и поправь».
2. Не выдумывай новую категорию.
3. Не подгоняй CPC под бюджет («тут поставлю 100, чтобы цифры сошлись») — это путь к сорванной кампании.

## Особые случаи

### Очень маленький бюджет (<15 000 ₽/мес)

Прямо: «15к/мес — меньше 100 кликов/мес, статистики на оптимизацию не наберётся. Рекомендации:
- увеличить до 30-50к минимум, или
- сузить географию до одного города, или
- запускаться только на одну самую горячую гипотезу».

### Очень большой бюджет (>500 000 ₽/мес)

«Бюджет крупный. Поверх расчёта суммарной частотности нужны точные кампании по сегментам (B2B vs B2C, гео, бренд vs категория). Расчёт даёт нижнюю границу — реальный объём ниши может быть в разы больше».

### Юридика/медицина/недвижимость/автокредиты

CPC 800-2500₽ — норма. Если маркетолог удивлён «у нас 200₽»: «средний CPC в вашей нише по справочнику — 1500₽. Если хочешь 200 — собирай только узкие НЧ-маски, где конкуренция ниже».

### Сезонность

Скилл считает усреднённый месяц. Если кампания под сезон — сноска: «частотность вырастет в 2-5 раз в пиковую неделю, бюджет тоже надо подкручивать».

## Стиль работы

- **Без воды.** Маркетологу нужно число и понимание, откуда оно.
- **Покажи источник CPC.** Критично.
- **Сценарии вместо одной цифры.** Один CPC = одна неточная цифра.
- **Не путать с конверсиями.** Этот скилл — охват и стоимость клика, не CAC/LTV.

## Связи в пайплайне

- **Вход:** бюджет и регион из `00_brief.md`; `01_masks.json` от `mask-builder` для оценки CPC (история → `keywordbids_get` → `forecast_bids` → справочник); (опц.) фактическая семантика для сравнения.
- **Выход:** `02_frequency.json` → используется в:
  - `wordstat-filter` (Шаг 4) — порог 150 + сравнение с целевой суммарной частотностью
  - полный сбор семантики (Шаг 3) — целевая суммарная частотность
  - `bidding-strategy` (Шаг 9) — целевой CPC по кампании

## Возобновление

Если `02_frequency.md` есть — изменились ли вводные (бюджет, CPC, собранная семантика)? Изменились — пересчитай. Нет — используем существующее.
