# Бриф — новый шаблон под короткий пайплайн

Используется на Шаге 0. **Это первый артефакт пайплайна**, без которого скилл не двигается дальше.

Бриф сознательно короткий: пайплайн тактический, и мы не задаём вопросов, ответы на которые в нём не используются (отраслевая аналитика, отдельный hypothesis builder и USP generator, buyer personas, анализ конкурентов, аудит посадочных — всё это вне зоны этого скилла). Это значит:

- **Не спрашиваем у клиента** то, что больше нигде не используется (например, маржу, LTV, портреты ЦА в формате JTBD).
- **Спрашиваем явно то, что раньше выводилось через отдельные этапы** — в первую очередь УТП и угол отстройки, которые теперь идут напрямую в Шаг 1 (маски) и Шаг 8 (объявления).

## Как задавать вопросы

**Одним блоком**, не по одному в чате. Маркетолог быстро отвечает на всё, а потом мы возвращаемся за уточнениями только если что-то критичное пропущено.

Если есть исходные материалы (бриф клиента, ТЗ, презентация, переписка, аналитика прошлых кампаний) — попроси приложить **до** заполнения брифа. Извлеки из них что сможешь, и в брифе спрашивай только недостающее. Это экономит маркетологу время.

## Шаблон вопросов

```
Бриф на создание рекламной кампании в Яндекс.Директе. Чтобы я мог запустить пайплайн, заполни 12 пунктов (13-й — по желанию):

1. Продукт/услуга — название, что это, ссылка на сайт.
   Если есть исходники (бриф клиента, ТЗ, аналитика) — приложи, заберу из них что смогу.

2. Тип сайта — лендинг / интернет-магазин / многостраничный?

3. Регион показа — РФ целиком / конкретный город / несколько городов?

4. Месячный бюджет — общая сумма на Директ в месяц, ₽.
   (Минимум 30-50к — иначе пайплайн предупредит.)

5. Каналы — только Поиск / только РСЯ / и Поиск, и РСЯ?
   Распределение бюджета в % если уже знаешь (например 60/30 или 100/0).

6. Тип запросов — НЧ / СЧ / ВЧ / все?
   (По умолчанию НЧ+СЧ. ВЧ возьмём только если бюджет ≥100к + продукт массовый + есть бренд.)

7. УТП продукта — главное обещание, отстраивающее от конкурентов.
   Формулировка вида: «единственные, кто делает X для Y» или «делаем X за N часов, а не недель».
   1-3 сужающих слова, которыми описываешь свой угол: премиум / срочно / ручной работы / для самозанятых / межгород и т.п.
   (Если нет настоящего УТП — скажи прямо, обсудим как позиционироваться без него.)

8. Цель в Метрике — что считаем конверсией?
   Название цели + конкретное событие (отправка формы X / клик по кнопке Y / переход на /thanks).
   Счётчик Метрики установлен? counter_id если знаешь.

9. CPA таргет — сколько готовы платить за целевое действие, ₽?
   Не знаешь точно — гипотеза от LTV/маржи.
   **Ценность конверсии** — сколько эта заявка стоит бизнесу (средний чек или маржа с сделки), ₽?
   Коллтрекинг подключён? (Calltouch / Callibri / Roistat / UIS / MANGO / нет)

10. Существующие материалы (опционально, но сильно ускоряют) —
    - готовый список ключей или семантика?
    - уже написанные объявления?
    - ассеты для РСЯ: лого, фото продукта, цвета бренда (HEX), шрифты?
    - предыдущая аналитика по этой нише?

11. Slug проекта — короткое имя для рабочей папки `direct-campaigns/<slug>/`.
    Маленькие латинские буквы через дефис, без пробелов и русских.
    Пример: vokal-school, crm-flow, evakuator-kazan.

12. Тематика — попадает ли продукт в лицензируемые или запрещённые категории?
    Медицина, финансы и займы, алкоголь, БАДы, оружие, азартные игры,
    недвижимость-долёвка, образование с лицензией — что-то из этого про вас?
    Если да: есть ли на руках лицензия / сертификат / документы? Какие именно?

13. (опц.) Ограничения и стоп-слова — чего нельзя писать в объявлениях,
    запрещённые формулировки, темы.
```

## Что делать, если маркетолог не знает какие-то поля

**По умолчанию проставляем разумные дефолты и помечаем как «гипотеза»**, чтобы маркетолог потом скорректировал:

| Поле | Дефолт | Откуда взять |
|------|--------|--------------|
| Тип запросов | НЧ + СЧ | Правило агентства |
| Распределение бюджета | 60 Поиск / 30 РСЯ / 10 Ретаргет (стандарт) или 100 Поиск (срочный спрос) | По типу ниши |
| CPA таргет | Считаем как LTV × 0.2 если есть LTV; иначе — флаг «гипотеза» и ставим Категория Б из `frequency-calculator.md` × 5 кликов на конверсию | Из брифа |
| Ценность конверсии | Дефолта нет: **не выдумываем**. Не назвали — пишем `null`, и на Шаге 10 приоритетные цели просто не передаются (счётчик Метрики привязывается всё равно) | Из брифа |
| Регион | Москва + СПб (если не указано) | Дефолт |
| УТП | Если нет — забираем H1 главной страницы инструментом чтения веб-страниц (например, `WebFetch`) + явно помечаем «не настоящее УТП, обсудить». Читать страницы нечем — спрашиваем УТП у маркетолога словами и помечаем пропуск | Сайт |

## Чего сознательно НЕ спрашиваем

- **Анализ конкурентов** — не проводим, маркетолог его делает отдельно если нужно.
- **Портреты ЦА (JTBD, боли, страхи)** — не нужны для тактической части. Если маркетолог приложит — извлечём.
- **Стратегические гипотезы запуска** — заменены полем 7 (УТП + сужающие слова).
- **Маржа и LTV в деталях** — заменены полем 9 (CPA таргет).
- **Подробная отраслевая аналитика** — заменена прогнозом CPC через MCP (Шаг 2) + справочником из `frequency-calculator.md`.
- **Аудит посадочных страниц** — этого этапа в пайплайне больше нет, маркетолог проверяет лендинги сам перед активацией кампаний.

## Формат артефакта `00_brief.md`

После ответа маркетолога — сразу собрать `direct-campaigns/<slug>/00_brief.md` со всеми 12 обязательными полями в явном виде. Поля «source: со слов клиента» / «source: главная страница сайта» / «source: гипотеза, требует подтверждения» — обязательны.

Если сайт прочитать было нечем, в конец `00_brief.md` добавь пометку о пропуске:

> ⚠️ **пропущено: нет чтения веб-страниц** — данные о продукте только со слов клиента. Потеряно: сверка УТП и бенефитов с тем, что реально написано на сайте. Как добрать: открыть сайт руками и уточнить поля 1, 7.

Пример:

```markdown
# Бриф: vokal-school

## 1. Продукт
- Название: Школа вокала «Голос»
- Что это: онлайн-школа вокала для взрослых, индивидуальные занятия с педагогом
- URL: https://vokal-shkola.ru

## 2. Тип сайта
- Лендинг (одностраничный)

## 3. Регион
- РФ + СНГ (русскоязычные)
- region_ids: [225] (Россия)

## 4. Бюджет
- 80 000 ₽/мес

## 5. Каналы
- Поиск + РСЯ
- Распределение: 60 / 40

## 6. Тип запросов
- НЧ + СЧ (ВЧ не берём — бюджет 80к < 100к минимума)

## 7. УТП и сужающие
- УТП: «Поставим голос за 3 месяца с педагогом из Большого театра» (source: H1 главной)
- Сужающие слова: +индивидуально, +педагогом, +большойтеатр
- Тип ниши: премиум-обучение (длинный цикл, эмоциональная покупка)

## 8. Цель в Метрике
- Главная цель: «Заявка на пробный урок» — отправка формы → /thanks
- counter_id: 87654321 (подтверждён, есть Метрика на сайте)

## 9. CPA таргет
- 1 500 ₽ за заявку на пробный урок (гипотеза от LTV 60к × 0.025)
- Ценность конверсии: 12 000 ₽ (средний чек абонемента) → идёт в `priority_goals` на Шаге 10
- Коллтрекинг: не подключён → предупредить о Фазе 3 на Шаге 10

## 10. Существующие материалы
- Нет готовых ключей / объявлений
- Логотип в svg есть, цвета: #1a1a1a / #d4af37
- Прошлая кампания за 2025-12 — слили 40к, CTR 1.2%, отказы 80% — изучить причины
  (загрузить аналитику, если есть выгрузка)

## 11. Slug
- vokal-school

## 12. Тематика
- Лицензируемая: да — образовательные услуги
- Документы: лицензия на образовательную деятельность №12345 от 2024-03-01, есть на руках
- Запрещённых категорий нет → стоп-гейт Шага 0 пройден

## 13. Ограничения
- Нельзя обещать «100% результат», «петь как Хворостовский»
- ОРД маркировка обязательна
```

⚠️ **Раздел 12 обязателен даже когда тематика обычная** — тогда пишем «Лицензируемых и запрещённых категорий нет». Стоп-гейт Шага 0 опирается именно на него: без явной записи агент не может подтвердить, что проверка была сделана. Сверка категорий — по `references/ad-legal-topics.md`.

## Гейт на выходе

Сводка в чат (5-7 строк):

```
Бриф собран:
- Продукт: Школа вокала «Голос», лендинг, vokal-shkola.ru
- Бюджет 80к/мес, РФ, Поиск 60% + РСЯ 40%
- УТП: «Поставим голос за 3 месяца с педагогом из Большого театра»
- Сужающие: +индивидуально, +педагогом, +большойтеатр
- Тип ниши: премиум-обучение, длинный цикл
- Цель: заявка на пробный (есть Метрика, counter_id 87654321)
- CPA таргет 1 500 ₽; коллтрекинг НЕ подключён (предупрежу о Фазе 3)

Бриф ОК — переходим к Шагу 1 (сбор масок)?
```

Прямой вопрос: «Всё верно? Иду дальше?»

## Связи в пайплайне

- **Выход:** `00_brief.md` + `_state.json` → используется во **всех** последующих шагах. Это единственный источник правды по продукту в пайплайне.
- **Нужная способность среды:** чтение веб-страниц по URL (например, инструментом `WebFetch`) — для извлечения H1 / УТП кандидатов / 5 пунктов о продукте. **Необязательна:** нет — спрашиваем те же 5 пунктов у маркетолога словами и помечаем пропуск.

## Возобновление

Если `00_brief.md` уже есть — спроси: «Бриф для <slug> уже собран. Используем существующий или пересобираем?»
