# Импорт кампании в Директ Коммандер

Используется на **Шаге 10** как один из способов заливки — особенно актуальный для **комбинаторных объявлений**, которые текущий MCP (`ads_add` умеет только классический `TextAd`) и прямой API из скилла не создают. Заливка комбинаторного объявления **штатно поддерживается** через XLS/XLSX, Директ Коммандер и API (справка №50) — а скилл уже генерирует xlsx на Шаге 8 (`scripts/generate_ads_xlsx.py`).

## Когда выбирать этот путь

- Модель комбинаторная (единственная актуальная) → `ads_add` объявление не зальёт → Коммандер (по xlsx) закрывает заливку целиком, без «доделать руками» построчно.
- Нет подключённого MCP/токенов → Коммандер работает с готовыми файлами скилла.
- Нужен визуальный ревью структуры перед отправкой на сервер.

Коммандер — **не единственный** способ (рядом: passthrough-API, если появится; ручной ввод в веб-интерфейсе), но для комбинаторных РК это самый прямой путь.

## Что нужно на входе

- `ads.xlsx` (+ `keywords.xlsx`) из `scripts/generate_ads_xlsx.py` (Шаг 8) и `warnings.txt` (проверить, что нет превышений лимитов).
- Установленный **Яндекс Директ Коммандер** (десктоп, Windows/macOS): https://yandex.ru/support/direct-commander/
- Доступ к рекламному аккаунту (логин пользователя).

## Шаги импорта

1. Открыть Директ Коммандер, войти под аккаунтом рекламодателя.
2. **«Получить» → кампании** (синхронизировать текущее состояние аккаунта), чтобы Коммандер знал контекст.
3. **«Импорт» → «Импортировать из файла»** → выбрать `ads.xlsx` (и при необходимости `keywords.xlsx`). Коммандер разбирает столбцы кампаний/групп/объявлений/ключей.
4. Проверить отчёт импорта: ошибки/предупреждения по лимитам и полям. Сверить с `warnings.txt` скилла.
5. Просмотреть созданные кампании/группы/объявления в дереве — убедиться, что комбинаторные объявления собрались (наборы заголовков/текстов, картинки/видео при наличии).
6. Догрузить то, что не кладётся из xlsx (минус-фразы кампании, быстрые ссылки/уточнения, точные ставки) — вручную в Коммандере или отдельным файлом.
7. **«Отправить»** изменения на сервер. Кампании создаются/остаются в статусе **DRAFT** («Черновик»/остановлены).

## Критично

- **Активацию делает только маркетолог** в интерфейсе Директа после финальной проверки (посадочные, Метрика, коллтрекинг, бюджеты, ОРД-маркировка). Скилл и Коммандер оставляют кампании выключенными.
- Всё, что не удалось импортировать/догрузить, фиксируется в `10_launch_log.md` списком «доделать руками».
