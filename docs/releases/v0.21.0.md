# v0.21.0 — заливка нескольких кампаний без отказов и лишних подтверждений

Обновление с v0.20.3.

Коротко: правки по итогам замера скорости «Запуска Директа» (aihub-681). Агент проверяет
символы в ключах и минус-фразах до заливки, собирает несколько кампаний в одном формате и
делает меньше однотипных запросов в кабинет.

## Что изменилось для вас

**1. Минус-фразы проверяются до заливки.** Фразу вроде «б/у» Директ не принимает и отклоняет
из-за неё всю кампанию. Теперь агент находит такие фразы ещё на этапе минус-слов и предлагает
замену («бу»). Если фраза общая для всех кампаний, вы увидите одно сообщение, а не шесть
отказов при заливке.

**2. Несколько кампаний — один пакет.** Объявления всех кампаний агент собирает в одном файле
понятного проверке формата. Он больше не переделывает файлы перед заливкой.

**3. Меньше «Разрешить» при заливке.** Ключи всех групп и ставки уходят одним запросом, а не по
запросу на кампанию. Если первая кампания не создалась из-за общей ошибки, агент не отправляет
остальные: исправляет причину и повторяет только то, что не прошло.

**4. Ключи в выгрузке = ключи в кабинете.** Фразы, которые Директ посчитал дублями («seo для
сайта» и «seo сайта»), агент убирает из выгрузки, а в итоге пишет число ключей в кабинете.

**5. «Без картинок» — значит без картинок.** Если вы отказались от картинок для РСЯ, агент не
спрашивает про цвета бренда и концепции и сразу идёт дальше. Цвета он спросит, только если
будет генерировать картинки.

**6. Меньше лишних шагов.** Если счётчик Метрики не нашёлся ещё при разведке, агент сразу готовит
инструкцию для ручной настройки целей. На платформе AI Hub он не проверяет новую версию на GitHub.

**Что не изменилось.** Кампании по-прежнему заливаются черновиками, запускает их маркетолог.
Платформа пока просит подтверждение на каждую запись в кабинет — одно разрешение на весь пакет
появится после доработки платформы (aihub-667).
