# v0.18.1 — РСЯ в ЕПК больше не выключается

Обновление с v0.18.0.

Коротко: кампания на поиск и РСЯ теперь создаётся с включённой РСЯ, а ошибки в быстрых ссылках
и отображаемой ссылке ловятся до заливки.

## Что изменилось для вас

**1. ЕПК на поиск и РСЯ создаётся с первого раза.**
Раньше на такой кампании Директ отвечал ошибкой 4000 «strategies are not compatible», и скилл
заливал кампанию с выключенной РСЯ. Теперь стратегия задаётся на поиске, а РСЯ идёт за ней —
так же, как при создании ЕПК в интерфейсе. Выключенной РСЯ будет только там, где вы сами решили
на Шаге 5 оставить кампанию «только Поиск».

**2. Ручные ставки — только без РСЯ.**
Директ не даёт совместить ручные ставки на поиске с показами в РСЯ. Если для кампании нужны
ручные ставки, скилл предложит сделать её «только Поиск» и спросит вас на Шаге 5.

**3. Проверка перед заливкой строже там, где строг Директ.**
Набор быстрых ссылок, у которого названия первых четырёх вместе длиннее 66 символов,
отображаемая ссылка с пробелом, подчёркиванием или другими лишними символами — останавливаются
до заливки. А текст объявления больше не считается слишком длинным из-за точек и запятых:
Директ их в лимит 81 символ не включает.

**4. Несколько групп в одной кампании.**
Отдельная группа появляется только под другую посадочную или под ВЧ-запросы — и такая
кампания заливается целиком, со всеми группами.

## Обновление

**Claude Code (плагин):** обновится сам при старте сессии, если включено автообновление.

**Claude Desktop / claude.ai:** скачайте `yandex-direct-manager.skill` из релиза и загрузите заново
в «Настройки → Возможности → Скиллы».

Подключения MCP менять не нужно. Технический список изменений — [`CHANGELOG.md`](../../CHANGELOG.md).
