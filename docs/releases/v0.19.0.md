# v0.19.0 — автотаргетинг настраивается сам

Обновление с v0.18.1.

Коротко: скилл сам задаёт категории и бренды автотаргетинга при заливке ЕПК. Пункт «зайти
в интерфейс и настроить автотаргетинг» из списка ручной работы ушёл.

## Что изменилось для вас

**1. Автотаргетинг больше не уходит с дефолтом Директа.**
Директ включает автотаргетинг в каждой группе ЕПК сам — и сразу со всеми категориями запросов
и всеми брендами, включая конкурентов. На Поиске его не выключить, а на узкой семантике он
забирает половину трафика группы и больше. Теперь скилл при заливке оставляет только те
категории и бренды, которые вы подтвердили на Шаге 5.

**2. Что предлагается по умолчанию.**
- обычная кампания — целевые и узкие запросы, без брендов и с вашим брендом;
- группа, где меньше 30 фраз, — плюс альтернативные, иначе показов почти не будет;
- брендовая кампания — только целевые запросы и только ваш бренд;
- бренды конкурентов — только если вы прямо просите конкурентный трафик в брифе.
На гейте Шага 5 вы видите этот набор по каждой кампании и можете поменять.

**3. Ставка автотаргетинга — только там, где она работает.**
При автостратегии Директ ставку автотаргетинга не применяет, а на «Максимуме кликов» не учитывает
и приоритет. Поэтому ставка задаётся только кампаниям «только Поиск» на ручных ставках. Если
Директ что-то сохранил, но не применяет, это будет в отчёте о заливке в разделе «Проверить руками».

## Обновление

**Claude Code (плагин):** обновится сам при старте сессии, если включено автообновление.

**Claude Desktop / claude.ai:** скачайте `yandex-direct-manager.skill` из релиза и загрузите заново
в «Настройки → Возможности → Скиллы».

Нужен MCP Директа с настройкой автотаргетинга — на хостовом сервере она уже есть, подключение менять
не нужно. Технический список изменений — [`CHANGELOG.md`](../../CHANGELOG.md).
