# v0.18.0 — обновления приходят сами

Обновление с v0.17.1.

Коротко: в Claude Code скилл теперь ставится плагином и дальше обновляется без вашего участия.
Маршрут создания кампании не изменился.

## Что изменилось для вас

**1. Установка плагином в Claude Code.**
Две команды в сессии Claude Code:

```
/plugin marketplace add ai-hub-open/claude-plugins
/plugin install yandex-direct-manager@ai-hub-open
```

Потом один раз включите автообновление: `/plugin` → **Marketplaces** → `ai-hub-open` →
**Enable auto-update**. После этого новые версии подтягиваются сами при старте сессии.

**2. Скилл сам скажет, что вышла новая версия.**
В начале работы скилл сверяет свою версию с GitHub. Если есть новее — коротко сообщит, что
изменилось и как обновиться, и спросит, продолжать ли на текущей. Это работает и в Claude Desktop,
где скилл загружен архивом. Нет интернета — проверка молча пропускается.

## Обновление

**Claude Code, раньше ставили папкой:** удалите `~/.claude/skills/yandex-direct-manager` и поставьте
плагином по шагу 1 — иначе скилл загрузится дважды. Python-зависимости не меняются.

**Claude Desktop / claude.ai:** скачайте `yandex-direct-manager.skill` из релиза и загрузите заново
в «Настройки → Возможности → Скиллы».

Подключения MCP менять не нужно. Технический список изменений — [`CHANGELOG.md`](../../CHANGELOG.md).
