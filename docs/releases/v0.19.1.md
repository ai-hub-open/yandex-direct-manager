# v0.19.1 — бриф без вопроса про slug

Обновление с v0.19.0.

Коротко: скилл больше не просит придумать служебное имя проекта латиницей. Он придумывает его
сам и показывает в сводке брифа.

## Что изменилось для вас

**1. Одним вопросом в брифе меньше.**
Раньше бриф спрашивал «Slug проекта — короткое имя для рабочей папки». Теперь скилл сам берёт
имя из названия продукта, например `vokal-school` или `evakuator-kazan`. Если бриф пришёл от
маркетинг-стратега, имя берётся из него.

**2. Имя видно один раз — в сводке брифа.**
Строка «Имя проекта: vokal-school — с него начнутся названия кампаний в кабинете». Хотите
другое — скажите на этом шаге, скилл возьмёт ваше.

**3. Бриф собранный раньше читается как прежде.**
Разделы файла брифа остались на своих местах, продолжить начатую кампанию можно без изменений.

## Обновление

**Claude Code (плагин):** обновится сам при старте сессии, если включено автообновление.

**Claude Desktop / claude.ai:** скачайте `yandex-direct-manager.skill` из релиза и загрузите заново
в «Настройки → Возможности → Скиллы».

Подключения MCP менять не нужно. Технический список изменений — [`CHANGELOG.md`](../../CHANGELOG.md).
