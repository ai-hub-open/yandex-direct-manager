# v0.20.0 — один этап без полного брифа

Обновление с v0.19.1.

Коротко: скилл умеет сделать один этап — только семантику, только минус-слова или только
объявления — и не спрашивает бюджет, каналы и цель в Метрике, если они для этого этапа не нужны.

## Что изменилось для вас

**1. «Собери семантику» — это просьба собрать семантику, а не запустить кампанию.**
Раньше скилл на такую просьбу задавал полный бриф из 11 пунктов. Теперь — не больше четырёх
вопросов одним сообщением: что рекламируем, регион, сужающие слова. То же для «собери минусы»
и «напиши объявления».

**2. «Бюджет не нужен, только семантика» — скилл переключается.**
Если вы начали полный бриф и передумали, скажите это. Скилл ответит одной строкой («Ок, только
семантика. Нужны регион и сужающие слова») и больше не спросит про бюджет и каналы.

**3. После этапа скилл останавливается.**
Короткая сводка и строка «Дальше можно: минус-слова — скажи». Следующий этап начнётся, только
когда вы попросите. «Продолжаем по Директу» тоже не запускает следующий шаг сам — скилл спросит,
что делать дальше.

**4. Без бюджета высокочастотные ключи на Поиск не попадают.**
Они не теряются: лежат среди отброшенных с причиной «нет бюджета», и это написано в сводке.
Захотите потом полную кампанию — собранную семантику заново собирать не нужно.

**Что не изменилось.** Проверка тематики (запрещённые и лицензируемые категории) работает в
любом режиме. Полная кампания по «сделай РК в Директе» идёт как раньше. В кабинет скилл
по-прежнему ничего не пишет без вашего «ОК».

## Обновление

**Claude Code (плагин):** обновится сам при старте сессии, если включено автообновление.

**Claude Desktop / claude.ai:** скачайте `yandex-direct-manager.skill` из релиза и загрузите заново
в «Настройки → Возможности → Скиллы».

Подключения MCP менять не нужно. Технический список изменений — [`CHANGELOG.md`](../../CHANGELOG.md).
