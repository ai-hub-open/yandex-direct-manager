# Журнал изменений

Версии — [semver](https://semver.org/lang/ru/): до 1.0 состав шагов и материалов может меняться.

## 0.8.0 — 2026-07-27

Сверка со справкой Яндекс Директа (422 статьи) и переход на единую модель объявлений.

- Исправлены устаревшие факты: актуальные названия стратегий торгов («Максимум конверсий» и семейство), пороги обучения, лимиты видео и изображений, обязательность автотаргетинга в ЕПК, правила модерации и запрещённые тематики.
- Единая модель объявлений — комбинаторное объявление ЕПК: классическая ТГО-модель удалена из скрипта сборки (площадка заморозила ТГО с 30.06.2026, автомиграция с 14.07).
- Новые справочники: юридически чувствительные тематики, импорт в Директ Коммандер, работа с Вордстатом в браузере без API-ключа.
- Пакетные стратегии, стоп-гейт по тематикам на первом шаге, обновлённые лимиты уточнений и минус-фраз.
- Тесты обновлены под единую модель (10 проходят).

## 0.7.1 — 2026-07-27

- Установщик зависимостей `install.py` с самопроверкой (Python ≥ 3.9, зависимости, smoke-тест модулей) и `requirements.txt`.
- Сборка переносимого архива скилла: `package.sh` + `scripts/package_skill.py`; архив приложен к релизу.
- Кода этапов воронки изменения не касаются.

## 0.7.0 — 2026-07-27

Первый публичный релиз.

- Полный цикл: семантика из Вордстата, разбивка НЧ/СЧ/ВЧ, минус-слова и кросс-минусация, объявления по лимитам Директа, цели Метрики, стратегия торгов, заливка кампании черновиком через MCP.
- Скрипты этапов и настройка MCP (`scripts/`), справочники и тесты.
- Номер версии отражает фактическую зрелость; изменения до 0.7.0 велись без журнала.
